# キーボードショートカット（プレイヤー）

動画プレイヤーウィンドウで使用できるキー操作です。

| キー | 動作 |
|---|---|
| Space | 再生/一時停止 |
| F / F11 | フルスクリーン切替 |
| M | ミュート切替 |
| V | コメント表示切替 |
| ← / → | -5秒 / +5秒 |
| Shift + ← / → | -10秒 / +10秒 |
| ↑ / ↓ | 音量+/- |
| Shift + N | 次の動画へスキップ |
| Shift + P | 前の動画へスキップ |
