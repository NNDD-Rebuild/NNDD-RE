# 検索タブ

キーワードやタグで動画を検索するタブです。使う検索の方式は、設定の「検索API」で選べます（[設定](/NNDD-RE/settings/)参照）。

- **スナップショット**（デフォルト）: 新着動画が検索に出るまで最大1日ほどかかりますが、タグ完全一致検索の精度が高めです
- **nvapi（即時反映）**: 投稿直後の動画もすぐに検索できますが、検索結果にタグ情報が含まれないため動画情報タブでのタグ表示ができません

## 検索方法

- **検索ワード入力欄**にキーワードを入力し、Enterキーまたは「検索」ボタンで実行します。
- **検索タイプ**
  - *キーワード*: タイトル・説明文・タグを対象にした全文検索
  - *タグ完全一致*: タグ欄の完全一致のみを検索
- **ソート順**: 再生数・コメント数・マイリスト数・いいね数（それぞれ多い順）、投稿日時の新着順・古い順、動画の長さの短い順・長い順の8種類から選べます。

検索ワードが `sm12345` のような動画ID形式の場合は、通常の検索の代わりに、その動画を直接取得します（1件だけ見つかった場合は、そのまま再生します）。生放送・マイリスト・シリーズのURLやIDを入力した場合は、自動で**生放送タブ**や**マイリストタブ**に移動して、そちらで開きます。

## 保存検索

- 検索欄の下にある保存名入力欄に名前を付けて「保存」を押すと、現在の検索条件（検索ワード・タイプ・ソート順）を保存できます。
- 画面左側の「保存した検索」一覧から、保存済みの検索条件をクリックすると、その条件で、すぐに検索を実行します。
- 不要になった保存検索は×ボタンで削除できます。

## 結果の表示

- グリッド/リスト表示切替ボタンで表示形式を変更できます（他タブと共通設定）。
- 1ページ32件で、画面下部の固定バーに「〇〇件中 XX–YY件表示」と表示され、「前」「次」ボタンでページ送りします。
- 「スナップショット」で検索したときは、投稿者の名前やアイコンが、少し遅れて表示されることがあります。
- 検索条件・結果・現在のページはタブを離れても保持され、検索タブに戻ると復元されます（アプリを再起動すると消えます）。

## 動画に対してできる操作

ランキングタブと同様に、再生・音声のみ再生・ダウンロード（通常/音声のみ）・ニコニコで開く・投稿者ページへの遷移・右クリックメニューが使えます。加えて、結果一覧の上部にある「連続再生」ボタンで、そのページの検索結果を順番に再生できます。

投稿者アイコンやユーザー名をクリックすると、**フォロー中タブ**でそのユーザーの投稿動画に絞り込んで表示されます。

## プレイヤーからのタグ検索

プレイヤーで動画のタグをクリックすると、検索タブに自動的に切り替わり、検索タイプが「タグ完全一致」に設定された状態でそのタグの検索が実行されます。
