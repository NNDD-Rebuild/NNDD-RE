# 検索タブ

キーワードやタグで動画を検索するタブです。使う検索の方式は、設定の「検索API」で選べます（[設定](/NNDD-RE/settings/)参照）。

- **スナップショット**（デフォルト）: 新着動画が検索に出るまで最大1日ほどかかりますが、タグ完全一致検索の精度が高めです
- **nvapi（即時反映）**: 投稿直後の動画もすぐに検索できますが、検索結果にタグ情報が含まれないため動画情報タブでのタグ表示ができません

## 検索方法

- **検索ワード入力欄**にキーワードを入力し、Enterキーまたは「検索」ボタンで実行します。
- **検索タイプ**
  - *キーワード*: タイトル・説明文・タグを対象にした全文検索
  - *タグ完全一致*: タグ欄の完全一致のみを検索
- **ソート順**: 再生数・コメント数・マイリスト数・いいね数（それぞれ多い順）、投稿日時の新着順・古い順、コメントが新しい順・古い順（最新のコメントが付いた順）、動画の長さの短い順・長い順の10種類から選べます。初期値は「再生数 多い順」です。
- 検索ワード欄には、設定の「検索履歴を保存する」がONの間、直近の検索ワードが候補として表示されます。

検索ワードが `sm12345` のような動画ID形式の場合は、通常の検索の代わりに、その動画を直接取得します（1件だけ見つかった場合は、そのまま再生します）。生放送・マイリスト・シリーズのURLやIDを入力した場合は、自動で**生放送タブ**や**マイリストタブ**に移動して、そちらで開きます。

## 保存検索

- 「検索」ボタンの右にある「保存名」入力欄に名前を付けて「保存」を押すと、現在の検索条件（検索ワード・タイプ・ソート順）を保存できます。
- 画面左側の「保存した検索」一覧から、保存済みの検索条件をクリックすると、その条件が検索欄に入力されます。ダブルクリックすると、その条件ですぐに検索を実行します。
- 一覧の上の「📁＋」で、保存検索を整理するフォルダを作れます（作成直後に名前の入力画面が開きます）。保存検索はドラッグ&ドロップでフォルダに出し入れできます。中身のあるフォルダを削除すると、確認のうえ、中の保存検索もまとめて削除されます。
- 保存検索の行にマウスを合わせて「✎」を押すと、名前・検索語・種別・並び順を編集できます。フォルダは名前を変更できます。
- 不要になった保存検索は×ボタンで削除できます。

## 結果の表示

- グリッド/リスト表示切替ボタンで表示形式を変更できます（他タブと共通設定）。
- 1ページ32件で、画面下部の固定バーに「〇〇件中 XX–YY件表示」と表示され、「前」「次」ボタンでページ送りします。
- 「スナップショット」で検索したときは、投稿者の名前やアイコンが、少し遅れて表示されることがあります。
- 検索条件・結果・現在のページはタブを離れても保持され、検索タブに戻ると復元されます（アプリを再起動すると消えます）。

## 動画に対してできる操作

ランキングタブと同様に、再生・音声のみ再生・ダウンロード（通常/音声のみ）・投稿者ページへの遷移・右クリックメニューが使えます（検索結果には「ニコ動」ボタンはありません）。加えて、結果一覧の上部にある「連続再生」ボタンで、そのページの検索結果を順番に再生できます。

投稿者アイコンや「ユーザー」ボタンをクリックすると、投稿者がユーザーなら**フォロー中タブ**でそのユーザーの投稿動画に絞り込んで表示され、チャンネルなら**マイリストタブ**にそのチャンネルとして遷移します。

## プレイヤーからのタグ検索

プレイヤーで動画のタグをクリックすると、検索タブに自動的に切り替わり、検索タイプが「タグ完全一致」に設定された状態でそのタグの検索が実行されます。
