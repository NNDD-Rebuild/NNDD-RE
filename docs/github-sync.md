# GitHub同期・バックアップ

設定を保存したGitHub Gist（非公開）を使って、複数端末の間でNNDD-REの設定・マイリスト・スケジュール等を同期する機能です。設定タブの「バックアップ」から利用します。

## ログイン

1. 「GitHubでログイン」をクリックすると、認証コードが表示されたダイアログが開きます
2. 自動的にブラウザで `https://github.com/login/device` が開くので、表示されたコードを入力して、GitHubアカウントで承認します
3. アプリは、承認が終わるまで自動で待機します（コードには有効期限があります）
4. 承認が完了すると「ログイン成功」と表示され、以降は設定画面に自分のGitHubユーザー名が表示されます

パスワードやトークンを直接入力する必要はありません。

## プロファイル

バックアップ対象は「プロファイル」という単位で管理し、複数作成できます。各プロファイルは1つのGistに対応します。

- 「+ 新規プロファイル」から名前を付けて作成
- プロファイルをクリックすると選択（アクティブ）状態になります
- 既存のGistに紐付けて使うことも、新規にGistを作ることもできます
- 不要なプロファイルは削除できます（GitHub上のGist自体は残ります）

## バックアップ対象データ（データスコープ）

プロファイルごとに、以下の7項目を個別にON/OFFできます。送る内容は、[プライバシー](/NNDD-RE/privacy/)も参照してください。

| スコープ | 内容 | 初期値 |
|---|---|---|
| アプリ設定 | プレイヤーの設定、ダウンロードの一部の設定（同時ダウンロード数、リトライ回数、クールダウン、全コメント取得、タイムシフトの保存先、429の待機時間）、視聴履歴を残さない設定、HTTPサーバーの設定（ポートなど）、LANライブラリの接続先、システムトレイ、画像キャッシュ、ログレベル。ログイン情報、保存先のパス、ウィンドウの位置、テーマなどの表示設定、検索API、ネイティブHLSやmux実装、帯域制限、生放送、Discord・Webhookの設定は含まれません。HTTPサーバーの待受範囲と許可するホスト名は、端末ごとの設定のため含まれません | ON |
| NGリスト | NGワード・NGユーザー・NGコマンド・NGタグ | ON |
| マイリスト一覧 | 登録済みマイリストのURL・名前・種別（動画一覧自体は含みません） | ON |
| スケジュール | 自動ダウンロードの予約設定 | ON |
| 保存検索 | 検索タブで保存した検索条件 | ON |
| 自作プレイリスト | ローカルプレイリストとその中身 | ON |
| 視聴履歴 | アプリ内で再生した動画の履歴 | OFF |

## アップロード・ダウンロード

- **アップロード**: 選択中のデータスコープの内容を常にGistへ反映します。未作成なら新規Gistを自動作成します
- **ダウンロード**: Gistの内容でローカルのデータを**全置換**します。誤って上書きしないよう、常に確認ダイアログを挟みます

**自動アップロード**をプロファイルごとにONにすると、アクティブなプロファイルに対してアプリ起動時・終了時に自動でアップロードされます。前回アップロード時からデータに変更がなければ通信自体スキップされます。ダウンロードは事故防止のため常に手動操作のみです。

## 過去の版に戻す

Gistには、アップロードのたびに、過去の版が残ります。バックアップの画面から過去の版の一覧を開き、任意の時点の内容を選んで復元できます。
