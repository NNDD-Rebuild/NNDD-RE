# プレイヤーウィンドウ

動画再生用のウィンドウです。各タブの「再生」からはこのウィンドウが開きます。見た目や動作の細かい調整は設定の「プレイヤー」で行います。

## コントロールバー

下部に再生/一時停止・シークバー・現在時間/総時間・音量・画質選択（複数画質がある動画のみ）・速度選択（0.25x〜2.0x）・コメント表示ON/OFF・ミニプレイヤー（Picture-in-Picture）・フルスクリーンボタンが並びます。連続再生中は前後の動画へ移動するボタンも表示されます。

コントロールバー全体の大きさは設定で小（初期値）・標準・大の3段階に変更できます。ウィンドウ表示中は、設定の「コントロールバーを常時表示」（初期値はON）がONの間、バーが隠れません。フルスクリーン中はマウスを動かすと表示され、2.5秒操作がないと自動的に隠れます。ローカル再生では、シークバーにマウスを合わせると、その位置のサムネイルがプレビュー表示されます。

音声のみで再生している場合は、映像に関する項目（画質選択・ミニプレイヤーなど）は表示されません。

## コメントの表示

ニコニコ動画に近い見た目で、コメントを流します。不透明度・サイズ倍率・表示秒数・フォント・ボールド・縁取り（縁の濃さ）・アンチエイリアスは設定の「プレイヤー」で調整できます。

- NGフィルタの強度（弱/中/強）は設定の「NGコメント」で選びます。「弱」ではNGワードは完全一致のときだけ適用され、「中」（初期値）では部分一致も適用されます。「強」ではさらに、10秒以内に5件以上連投したユーザーのコメントも自動非表示になります
- NGの種類に「許可ID」を追加できます。コメントリストの「許可IDのみ」にチェックを入れると、許可IDに登録したユーザーと投稿者のコメントだけを表示します（このとき、NGワードなどは使われません）
- 「コメントアート (CA) 保護」を有効にすると、AA（アスキーアート）のようなコメントが通常コメントと重ならないよう別レイヤーで描画されます
- シーク時はコメントも即座に再描画されます

## コメント一覧

コメントリストは設定の「プレイヤー」→「表示方式」で「タブ表示」（サイドパネルのタブ）または「浮動ウィンドウ」（コントロールバー上の「💬 コメント一覧」ボタンで開く独立したウィンドウ）として表示できます。一覧では時間・コメント本文・ユーザーID・投稿日時・番号・オプション（コマンド）が確認でき、「時間」「投稿日時」「番号」の列ヘッダーのクリックでソート、「フィルター…」欄で本文/ユーザーID/コマンドによる絞り込みができます。「追従」で再生位置の行に自動でスクロールします。数万件規模のコメントでも仮想スクロールで軽快に動作します。

コメント行を右クリックすると、そのユーザーをNGにする・そのコメントをNGワードに追加する・そのユーザーを許可IDに追加する（それぞれ、登録済みなら解除）といった操作ができます。NGは全動画に共通で適用されますが、ニコニコのアカウントごとに分かれています（アカウントを切り替えると、そのアカウントのNGが使われます）。「NG一覧」ボタンから一括確認・追加・解除できます。NGに該当するコメントは一覧から隠れ、「NG表示」にチェックを入れると取り消し線付きで表示されます。

ローカル再生時は「再取得」ボタンでコメントを差分取得し、コメントXMLに追加できます。

サイドパネルには他に、「動画情報」（タイトル・投稿者・タグ・説明文）、「過去コメント」（通常の動画のみ。生放送をダウンロードした動画には表示されません）、「シリーズ」（動画がシリーズに属するとき）、「関連動画」（ストリーミング再生のとき）のタブも表示されます。投稿者名をクリックするとフォロー中タブにその投稿者の動画が表示されます。タグはダブルクリックで検索タブへ、右クリックで「ニコニコ大百科で開く」・「タグをコピー」（ライブラリのタグ一覧の右クリックにも「ニコニコ大百科で開く」があります）が選べます。説明文中のマイリストURL・シリーズURLはクリックでマイリストタブに、sm/nm/so/ss番号の動画リンクは、設定の「動画リンクをプレイヤーで開く」（初期値はON）がONならこのアプリのプレイヤーで、OFFなら外部ブラウザで開きます。

## 連続再生

以下のいずれかの条件で自動連続再生が有効になります。

- サイドパネルの「シリーズ」タブの「連続再生」にチェックを入れた場合（シリーズに属する動画のとき）
- ストリーミング再生中に、サイドパネルの「関連動画」タブの「連続再生」にチェックを入れた場合
- ローカル再生でフォルダ内に複数動画があり、コントロールバー上の「フォルダ連続再生」にチェックを入れた場合
- 検索・マイリスト・ライブラリの「▶ 連続再生」ボタンで開始した場合（マイリストでは、自作プレイリストを開いて動画を再生したときも、プレイリストの並び順で連続再生されます）

ストリーミング再生では、残り時間5秒を切ると次の動画を裏側で先読みするため、切り替えはほぼ瞬時に行われます。次の動画が見つからない場合は自動でスキップし、10回連続で失敗するとエラーメッセージを表示して止まります。

## その他プレイヤー設定と連動する機能

- **音量ノーマライズ**: 動画ごとの音量差を自動で均します
- **リピート再生**: 動画終了後、自動で最初から再生します（コントロールバーの 🔁 ボタンでも切り替えられます。ONの間は、連続再生の次の動画へは進みません）
- **投稿者フィルター**: 本家NNDDで保存した動画に付いている、投稿者が設定したコメントの置き換えを適用します（設定の「プレイヤー」の「投稿者フィルターを有効にする」で切り替え。新しくダウンロードした動画には、この情報はありません）
- **続きから再生**: 設定の「続きから再生する」（初期値はOFF）がONのとき、前回の再生位置から再開します（詳細は[履歴](/NNDD-RE/history/)を参照）
- **デフォルト画質/速度/音量**: 新しく開いた動画に最初から適用される値です。「再生速度を次の動画に引き継ぐ」をONにすると、プレイヤーで変えた速度が次の動画にも適用されます
- **再生方式**: 設定の「ストリーミング再生」で、内蔵プレイヤー（HLS即時再生。ネイティブ／プロキシ）か、ニコニコ公式プレイヤーの埋め込み（webview）を選べます。埋め込みでは、ニコニコ動画の視聴ページで再生されます
- **＠ジャンプ**: 投稿者コメントのニコスクリプトの＠ジャンプで別の動画へ移るとき、設定の「＠ジャンプ」（確認して移動／確認せず移動／無効）に従います
- **視聴履歴を残さない**: 設定の「全般」→「プライバシー」でONにしていて、年齢制限などでゲスト扱いでは再生できない動画を開いたときは、履歴を残して再生するか確認するダイアログが出ます

## キーボードショートカット

| キー | 動作 |
|---|---|
| Space | 再生/一時停止 |
| F / F11 | フルスクリーン切替 |
| M | ミュート切替 |
| V | コメント表示切替 |
| ← / → | -5秒 / +5秒 |
| Shift + ← / → | -10秒 / +10秒 |
| ↑ / ↓ | 音量 +/-（5%ずつ） |
| Shift + N | 次の動画へスキップ |
| Shift + P | 前の動画へスキップ |

- 入力欄に文字を入力しているときは、ショートカットは働きません
- 生放送のプレイヤーでは、Shift + N / P は使えません。← / → は、タイムシフトと追っかけ再生のときだけ使えます
- メインウィンドウでは、Ctrl（Mac は Cmd）+ O で「動画を開く」ダイアログが開き、動画のID・URL、またはローカルの動画ファイルを指定して再生できます
