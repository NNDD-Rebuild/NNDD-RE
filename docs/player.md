# プレイヤーウィンドウ

動画再生用のウィンドウです。各タブの「再生」からはこのウィンドウが開きます。見た目や動作の細かい調整は設定の「プレイヤー」で行います。

## コントロールバー

下部に再生/一時停止・シークバー・現在時間/総時間・音量・画質選択（複数画質がある動画のみ）・速度選択（0.25x〜2.0x）・コメント表示ON/OFF・ミニプレイヤー（Picture-in-Picture）・フルスクリーンボタンが並びます。連続再生中は前後の動画へ移動するボタンも表示されます。

コントロールバー全体の大きさは設定で小・標準・大の3段階に変更できます。フルスクリーン中はマウスを動かすと表示され、2.5秒操作がないと自動的に隠れます。

音声のみで再生している場合は、映像に関する項目（画質選択・ミニプレイヤーなど）は表示されません。

## コメントの表示

ニコニコ動画に近い見た目で、コメントを流します。不透明度・サイズ倍率・表示秒数・フォント・ボールド・縁取り・アンチエイリアスは設定で調整できます。

- NGフィルタの強度（弱/中/強）に応じて、NGワード・NGユーザー・NGコマンドの適用範囲が変わります。「強」では10秒以内に5件以上連投したユーザーのコメントも自動非表示になります
- NGの種類に「許可ID」を追加できます。コメント一覧の「許可IDのみ」にチェックを入れると、許可IDに登録したユーザーと投稿者のコメントだけを表示します（このとき、NGワードなどは使われません）
- 「コメントアート保護」を有効にすると、AA（アスキーアート）のようなコメントが通常コメントと重ならないよう別レイヤーで描画されます
- シーク時はコメントも即座に再描画されます

## コメント一覧

コメント一覧は設定で「サイドパネルのタブ」または「独立したウィンドウ」として表示できます。一覧では時間・コメント本文・ユーザーID・投稿日時・番号・オプション（コマンド）が確認でき、列ヘッダーのクリックでソート、テキスト入力欄で本文/ユーザーID/コマンドによる絞り込みができます。数万件規模のコメントでも仮想スクロールで軽快に動作します。

コメント行を右クリックすると、そのユーザーをNGにする・そのコメントをNGワードに追加する・そのユーザーを許可IDに追加する、といった操作ができます。NGに追加した内容は他の動画再生にもすべて共通で適用され、「NG一覧」ボタンから一括確認・解除できます。

ローカル再生時は「再取得」ボタンでコメントXMLを再取得し、差分だけ追加できます。

サイドパネルには他に、動画情報（タイトル・投稿者・タグ・説明文）、過去コメント（通常の動画のみ。生放送をダウンロードした動画には表示されません）、シリーズ内の動画一覧、関連動画の一覧のタブも表示されます。タグはダブルクリックで検索タブへ、右クリックで「ニコニコ大百科で開く」（ライブラリのタグ一覧の右クリックにも同じ項目があります）、説明文中のsm/nm/so番号・マイリストURL・シリーズURLはクリックでそれぞれ該当ページへ遷移します。

## 連続再生

以下のいずれかの条件で自動連続再生が有効になります。

- シリーズに属する動画を再生した場合（サイドパネルの「シリーズ」タブでON/OFF）
- ストリーミング再生中の関連動画（サイドパネルの「関連動画」タブでON/OFF）
- ローカル再生でフォルダ内に複数動画がある場合（コントロールバー上のチェックボックス）
- 検索結果・マイリスト一覧から「連続再生」ボタンで開始した場合

残り時間5秒を切ると次の動画を裏側で先読みするため、切り替えはほぼ瞬時に行われます。次の動画が見つからない場合は自動でスキップし、10回連続で失敗するとエラーメッセージを表示して止まります。

## その他プレイヤー設定と連動する機能

- **音量ノーマライズ**: 動画ごとの音量差を自動で均します
- **リピート再生**: 動画終了後、自動で最初から再生します（コントロールバーの 🔁 ボタンでも切り替えられます。ONの間は、連続再生の次の動画へは進みません）
- **投稿者フィルター**: 本家NNDDで保存した動画に付いている、投稿者が設定したコメントの置き換えを適用します（設定の「プレイヤー」で切り替え。新しくダウンロードした動画には、この情報はありません）
- **続きから再生**: 前回の再生位置から再開します（詳細は[履歴](/NNDD-RE/history/)を参照）
- **デフォルト画質/速度**: 新しく開いた動画に最初から適用される値です

## キーボードショートカット

| キー | 動作 |
|---|---|
| Space | 再生/一時停止 |
| F / F11 | フルスクリーン切替 |
| M | ミュート切替 |
| V | コメント表示切替 |
| ← / → | -5秒 / +5秒 |
| Shift + ← / → | -10秒 / +10秒 |
| ↑ / ↓ | 音量 +/-（5%ずつ） |
| Shift + N | 次の動画へスキップ |
| Shift + P | 前の動画へスキップ |

- 入力欄に文字を入力しているときは、ショートカットは働きません
- 生放送のプレイヤーでは、Shift + N / P は使えません。← / → は、タイムシフトと追っかけ再生のときだけ使えます
- メインウィンドウでは、Ctrl（Mac は Cmd）+ O で、動画を開けます
