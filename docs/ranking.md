# ランキングタブ

ニコニコ動画のジャンル別ランキングを表示するタブです。

## 画面構成

- **ジャンル選択**: 総合・ゲーム・アニメ・ボカロ・音声合成実況・解説・劇場・エンタメ・音楽・歌ってみた・踊ってみた・演奏してみた・解説・講座・料理・旅行・アウトドア・自然・乗り物・技術・工作・社会・政治・時事・MMD・VTuber・ラジオ・スポーツ・動物・その他・例のソレ の24種類から選択します。起動時にニコニコ動画側から最新のジャンル一覧を取得し、取得に失敗した場合はアプリ内蔵の一覧を使います。
- **サブカテゴリ（トレンドタグ）選択**: ジャンルの中でさらに人気のタグを絞り込みます。「総合」ジャンルなど一部のジャンルには存在しません。ジャンルを切り替えるとサブカテゴリの選択は自動的にリセットされます。
- **集計期間選択**: 毎時・24時間・週間・月間・全期間の5種類から選びます。クリックすると即座にランキングが切り替わります。
- **更新ボタン**: 現在の条件でランキングを再取得します。
- **グリッド/リスト表示切替**: 画面右上のボタンで切り替えます。この設定は他のタブ（検索・マイリスト等）とも共通です。

## 表示される動画の情報

各動画には以下が表示されます。

- サムネイル画像（ホバーすると0.5秒後に冒頭12秒のプレビューが自動再生されます。視聴履歴には記録されません）
- ランキング順位バッジ（左上）
- 動画の長さ（右下）
- チャンネル動画バッジ「CH」（右上、黄色）
- 視聴済みバッジ（左下の目玉アイコン。このアプリでの再生履歴とニコニコ動画本家の視聴履歴の両方を見て判定します）
- タイトル、投稿者アイコン・ニックネーム
- 再生数・コメント数・マイリスト数・投稿日時

ダウンロード済みの動画は「DL」ボタンが緑色になり、クリックするとコメントのみ再取得します。

センシティブな動画（R18等の閲覧注意フラグ付き）を表示するかどうかは、設定の「ランキング・検索・マイリスト」タブにある「センシティブな動画を隠す」で制御します。

## 動画に対してできる操作

- **再生**: 「再生」ボタン、またはサムネイルのダブルクリック
- **音声のみ再生**: 右クリックメニューから
- **ダウンロード**: 「DL」ボタン（通常ダウンロード）。ボタン横の▼から「音声のみダウンロード」も選べます
- **ニコニコ動画で開く**: 「ニコ動」ボタンでブラウザの視聴ページを開きます
- **投稿者ページへ移動**: 投稿者アイコン/「ユーザー」ボタンをクリックすると、投稿者がユーザーなら**フォロー中タブ**にそのユーザーの投稿一覧として、チャンネルなら**マイリストタブ**にそのチャンネルとして遷移します
- **右クリックメニュー**: 再生・音声のみ再生・ダウンロード（またはコメント再取得）・ニコニコで開く・マイリストへ追加

ページネーションはなく、取得した一覧をそのままスクロールして閲覧します。
