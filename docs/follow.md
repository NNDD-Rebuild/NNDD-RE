# フォロー中タブ

ニコニコ動画でフォローしているユーザーの新着動画を表示するタブです。

## 画面構成

**左側**の「フォロー中ユーザー」に、ニコニコ動画でフォローしているユーザーの一覧が表示されます（読み込み済みの新着動画で最新投稿日時が新しい順）。フォロー中のユーザーはログイン中のアカウントのものが表示され、アカウントを切り替えると取得し直します。「すべて」ボタンをクリックすると、特定ユーザーに絞らずフォロー中全員の新着をまとめて表示します。ユーザーをクリックすると、そのユーザーの投稿に絞り込まれ、もう一度クリックすると解除されます。

**右側**がメインの表示エリアです。

- ユーザーを絞り込んでいるとき、画面上部に「投稿動画」「マイリスト」「シリーズ」の3つのサブタブが表示され、それぞれそのユーザーの投稿動画・公開マイリスト・シリーズを見られます。サブタブの並びには、そのユーザーのページをブラウザで開く「ニコニコで開く」ボタンもあります。
- 「すべて」表示中は投稿動画のフィードのみ表示します（見出しは「フォロー中の新着動画」）。
- ツールバーには、絞り込み中の「✕ 解除」ボタン（「すべて」に戻ります）、「↺」再読み込みボタン（絞り込みも解除して先頭から読み直します）、グリッド/リスト表示の切り替えがあります。表示形式の切り替えはこのタブだけに効き、初期値は設定の「表示・検索」の「デフォルト表示」です。

## ページネーション

- **「すべて」表示中**: 1ページ32件です。「次 ▶」で続きを取得し、「◀ 前」で戻れます。
- **ユーザー絞り込み中**: 1ページ32件です。「◀ 前」「次 ▶」ボタンでページを送ります。件数は「N 件中 a–b 件表示」と表示されます。

## 動画・マイリスト・シリーズに対してできる操作

投稿動画は他タブと同じ動画カードで表示され、再生・音声のみ再生・ダウンロード・ニコニコで開く・右クリックメニューが使えます。「すべて」表示中は、投稿者アイコン/「ユーザー」ボタンからその投稿者の投稿一覧に絞り込めます（ユーザーを絞り込み中のカードにはありません）。ダウンロード済みかどうかも一括判定してバッジ表示されます。

マイリスト/シリーズのサブタブでは、一覧のクリックで**マイリストタブ**にその内容が表示されます。公開されているものがない場合は「公開マイリストが見つかりませんでした。」「公開シリーズが見つかりませんでした。」と表示されます。

## 他タブ・プレイヤーからの一時表示

プレイヤーで投稿者アイコンをクリックしたり、ランキング・検索の動画カードの投稿者アイコン/「ユーザー」ボタンをクリックしたりすると、フォロー中タブに切り替わりそのユーザーの投稿一覧が表示されます（チャンネルの場合はマイリストタブに遷移します）。フォローしていないユーザーでもこの方法で一時的に表示できますが、フォロー中ユーザー一覧には追加されません。

生放送の「フォロー中 (放送中)」「フォロー中 (放送予定)」は、このタブとは別に、フォローしている放送者の生放送を一覧にします。[生放送](/NNDD-RE/live/)を参照してください。
