# 内蔵HTTPサーバー・LAN共有

NNDD-REには内蔵HTTPサーバーがあり、他のアプリやブラウザとの連携、同一LAN上の別NNDD/NNDD-REとのライブラリ共有に使われます。

## 内蔵HTTPサーバーの起動

設定 → 全般 → 内蔵HTTPサーバー「起動」をクリックすると `http://127.0.0.1:<ポート>/` （デフォルト12345番）で待受を開始します。「QRコードを表示」でスマホから接続用のQRコードを表示できます（LAN内のIPアドレスを自動検出。取得できない場合は`localhost`になります）。

- デフォルトでは `127.0.0.1`（自分のPCから）のみアクセス可能です
- 「LAN内からのアクセスを許可」をONにすると同じLAN内の他端末からもアクセス可能になります。認証機構はないため、信頼できるネットワーク内でのみ有効にしてください
- 「動画ファイルのストリーミング配信を許可」をOFFにすると動画本体を配信するエンドポイントが無効になり、ライブラリ情報の閲覧のみ許可されます
- 「マイリスト情報の共有を許可」で `/api/mylist` 等のマイリスト系エンドポイントの有効/無効を切り替えられます

## エンドポイント一覧

| エンドポイント | メソッド | 用途 |
|---|---|---|
| `/health` | GET | ヘルスチェック |
| `/api/library` | GET | ライブラリ動画一覧（JSON） |
| `/api/mylist` | GET | 登録マイリスト一覧（JSON） |
| `/api/video/:id` | GET | 個別動画情報（JSON） |
| `/api/video/:id/stream` | GET | 動画ストリーミング（Range対応） |
| `/api/video/:id/thumb` | GET | サムネイル画像 |
| `/api/video/:id/comments` | GET | コメント一覧（JSON） |
| `/library` | GET | ブラウザ用HTMLライブラリページ（グリッド/リスト切替、タグ・フォルダ検索対応） |
| `/NNDDServer` | POST | 旧NNDD互換XMLプロトコル（動画一覧・マイリスト一覧取得等） |
| `/NNDDServer/:videoId` | GET | 旧仕様 動画ストリーミング |

## LANライブラリ（リモートNNDD参照）

同じLAN上で動いている別のNNDD-RE、または本家NNDDの内蔵HTTPサーバーに接続し、そちらのライブラリを閲覧・再生できる機能です。

設定 → 全般 → 「LANライブラリ（リモートNNDD参照）」で接続先のIPアドレスとポートを指定します。本家NNDDのデフォルトポートは12300、NNDD-REは12345です。接続先側でも内蔵HTTPサーバー（本家では「サーバー設定」）を有効にしておく必要があります。

接続すると[ライブラリタブ](/NNDD-RE/library/)の左側にリモートライブラリの一覧が表示され、接続状況（接続中/接続失敗）が確認できます。動画IDやファイル名の一覧を閲覧し、再生することができます。ダウンロード（自分のライブラリへの取り込み）には対応していません。

本家NNDD（ActionScript版）との通信はXMLベースの互換プロトコル（`/NNDDServer` 系エンドポイント）で行われるため、新旧どちらのNNDDとも接続できます。
