# 内蔵HTTPサーバー・LAN共有

NNDD-RE には内蔵のHTTPサーバーがあります。スマホや他のPCのブラウザから、NNDD-RE のライブラリを閲覧・再生するときに使います。また、同じネットワーク内の別の NNDD / NNDD-RE のライブラリを参照する「LANライブラリ」も、このページで説明します。

## 内蔵HTTPサーバーの起動

設定 → 外部ツール・連携 → サーバー・LAN →「内蔵HTTPサーバー」で「起動」を押すと、`http://127.0.0.1:<ポート>/library`（ポートの初期値は12345）で待受を開始します。サーバーは、初期状態では起動していません。

「QRコードを表示」を押すと、スマホで読み取って接続できるQRコードが表示されます（LAN内のIPアドレスを自動で調べます。調べられなかった場合は `localhost` になります）。

### 設定項目

- **待受範囲**: サーバーが受け付けるアクセスの範囲です。変更は、サーバーを再起動したあとに反映されます
  - **このPCのみ**（初期値）: このPC自身からしかアクセスできません
  - **LAN内の他端末からのアクセスを許可**: 同じLAN内の他の端末（スマホなど）からもアクセスできます。ファイアウォールがポートを遮断している場合は、受信を許可する設定が別に必要です
  - **Tailscale**: 後の節を参照してください
- **起動時に自動起動する**: NNDD-RE を起動するたびに、サーバーも自動で起動します
- **ポート**: 待受のポート番号です（1024〜65535、初期値は12345）
- **動画ファイルのストリーミング配信を許可**: OFFにすると、動画そのものの配信が止まり、ライブラリの情報の閲覧だけが許可されます。動画の再生まで他人に見せたくないときは、OFFにします
- **マイリスト情報の共有を許可**: マイリストの情報を、他の端末に見せるかどうかを選びます
- **追加で許可するホスト名**: 許可していない名前でのアクセスは、拒否されます。IPアドレス、`localhost`、PCの名前、`*.local`、`*.ts.net` は、自動で許可されます。独自のドメイン名（例: `nndd.example.lan`）でアクセスするときだけ、ここに追加します

> **注意**: 内蔵HTTPサーバーには、ログインやパスワードによる認証がありません。「LAN内の他端末からのアクセスを許可」や Tailscale を選ぶのは、信頼できるネットワークだけにしてください。

## 外出先からアクセスする（Tailscale）

[Tailscale](https://tailscale.com/) を使うと、外出先からも、自宅のNNDD-REのライブラリに接続できます。接続する端末にも、Tailscale が必要です。

- **このPCに Tailscale を入れている場合**: 「待受範囲」を「LAN内の他端末からのアクセスを許可」にするだけで、Tailscale 経由でも届きます。画面に、Tailscale のURL（`100.x.x.x`）も表示されます
- **このPCに Tailscale を入れていない場合**: 「待受範囲」を「Tailscale」にします。NNDD-RE が、PC とは別の「NNDD-RE 専用の端末」として、Tailscale のネットワークに参加します。LAN内の他の端末からも、IPアドレスでアクセスできます

「Tailscale」を使うときの準備です。

1. 設定 → 外部ツール・連携 → サーバー・LANで、Tailscale 用のツールを取得します（NNDD-RE のプロジェクトが配布しているツールを取得し、改ざんされていないかを検証してから使います）
2. サーバーを起動すると、ログイン用のページが表示されます。そのページで承認します（Auth key を使う場合は、使い捨てで期限付きのものを使ってください）
3. 端末の名前を、設定できます

アクセスできる端末は、Tailscale の管理画面の ACL で絞れます。例えば、Auth key にタグ `tag:nndd-re` を付けて作成し、次のように許可します。

```
{ "action": "accept", "src": ["autogroup:member"], "dst": ["tag:nndd-re:80"] }
```

設定 → 外部ツール・連携 → サーバー・LANの「ログアウト（端末を削除）」を押すと、Tailscale のネットワークから端末を削除して、ログイン状態を消します。

## LANライブラリ（別のNNDD / NNDD-REを参照する）

同じLAN上で動いている別の NNDD-RE、または本家NNDDのサーバーに接続して、そのライブラリを閲覧・再生する機能です。

設定 → 外部ツール・連携 → サーバー・LAN →「LANライブラリ（リモートNNDD参照）」で、接続先のIPアドレスとポートを指定します。ポートの初期値は、本家NNDDが12300、NNDD-REが12345です。接続先でも、内蔵サーバー（本家NNDDでは「サーバー設定」）を有効にしておく必要があります。

接続すると、[ライブラリ](/NNDD-RE/library/)タブの左側に、リモートのライブラリが表示されます。接続の状態（接続中 / 接続失敗）も確認できます。動画の一覧を閲覧して、再生できます。自分のライブラリに取り込むダウンロードには、対応していません。
