# NNDDからの移行

MineAP氏作の本家NNDD（Adobe AIR版）から NNDD-RE へ乗り換えるときの手順です。NNDD-RE は、本家NNDDとの互換性を目指して作っています。ただし、見た目や操作が同じではないため、使い始める前にこのページを確認してください。

## NNDD-RE にしかないもの・変わったもの

- 新ニコニコAPI（V3 DMS）に対応して、ダウンロードします
- 生放送の視聴・録画、フォロー中の新着、GitHub同期、内蔵HTTPサーバーなど、本家にはなかった機能があります
- 画面のデザインや、操作の細かい部分は、本家と同じではありません

## 本家NNDDからインポートする

本家NNDDの設定やデータを、NNDD-REに取り込めます。設定 → 全般 → 「本家NNDDからインポート」を使います。

本家のファイルは**読み取るだけ**で、書き換えません。ニコニコのログイン情報は取り込みません（NNDD-REで、あらためてログインしてください）。

### 取り込める内容

| 項目 | 備考 |
|---|---|
| 設定 | 対応する項目だけが取り込まれます |
| NGリスト | NGワード・NGユーザー・NGコマンド・許可ID・NGタグ |
| 検索・マイリストの履歴 | それぞれ直近10件 |
| マイリスト | 本家のフォルダ構成も、そのまま取り込まれます |
| 保存検索 | フォルダ構成と、「コメントが新しい順」などの並び順も、そのまま取り込まれます |
| 再生履歴 | |
| プレイリスト | |
| ライブラリの情報 | 再生回数・最後に再生した日・タグ。動画ファイルが見つかったものだけです |
| DLキュー | 実験的な機能です。初期状態では取り込まない設定になっています |

### 手順

1. NNDD-REで、設定 → 全般 → 「本家NNDDからインポート」を開きます。
2. **取り込み元を選びます。** 本家のデータは、通常 `%APPDATA%` の下の NNDD のフォルダ（`Local Store`）にあります。自動で見つかる場合は選ぶだけです。見つからない場合は、`Local Store` フォルダ（または、その中の `system` フォルダ）を手動で指定します。
3. 「内容を確認」を押します。項目ごとに、取り込み方を選べます。
   - **マージ**: NNDD-RE にあるデータを残して、追加します
   - **置換**: NNDD-RE のデータを、先に削除してから取り込みます
   - **取り込まない**
4. 内容を確認して、取り込みを実行します。実行前に、NNDD-RE のデータベースが自動でバックアップされます。

### ライブラリ（動画ファイル）の引き継ぎ

インポートは、動画ファイルをコピーしたり移動したりしません。本家のライブラリに記録されているファイルの場所を調べて、**ファイルが見つかったものだけ**を、NNDD-RE のライブラリに登録します。

- 本家とは別のドライブや別のPCに、動画フォルダを移した場合は、「旧ルート→新ルート」の入力欄に、本家で使っていたフォルダと、今のフォルダを指定してください
- ファイルが見つからなかった動画は、「動画ファイルが見つからない」として、取り込みの対象から外れます
- プレイリストの動画が、ライブラリにない場合は、ダウンロードするかどうかを確認されます

## ファイル名の互換性

NNDD-RE は、動画のIDを角括弧で含むファイル名から、動画IDとタイトルを認識します。

- 動画ファイルの例: `タイトル - [sm12345].mp4`
- 認識できる拡張子: `.mp4` `.flv` `.swf` `.webm` `.mkv` `.m4a`
- コメントは `[sm12345].xml`、動画の情報は `[sm12345][ThumbInfo].xml`、サムネイルは `[sm12345][ThumbImg].jpeg` に保存します
- サブフォルダの中も調べます

本家NNDDで保存した動画のフォルダを、NNDD-RE の「動画の保存先」に指定して「ライブラリを更新」すると、同じ形式のファイルが一覧に表示されます。

ただし、動画の情報のファイル（`[ThumbInfo].xml`）がない動画は、ライブラリに登録されません。

## 本家NNDDと併用する

NNDD-RE のライブラリのデータベースは、本家NNDDのデータベースとは別のファイルです。

LANライブラリの機能を使うと、本家NNDDの内蔵サーバーに接続して、本家のライブラリを閲覧・再生することもできます。詳しくは[内蔵HTTPサーバー・LAN共有](/NNDD-RE/http-server-integration/)を参照してください。
