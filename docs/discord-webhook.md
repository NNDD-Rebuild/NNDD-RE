# Discord連携・Webhook通知

設定 → 全般から利用できる、外部サービスとの通知連携です。

## Discord Rich Presence

Discordデスクトップアプリを起動している状態でONにすると、自分のDiscordプロフィールの「アクティビティ」欄に、今NNDD-REで再生中の動画情報が表示されます。

表示できる項目（個別にON/OFF可能）:

- 動画タイトル
- 経過時間（再生位置に応じて進捗バー表示）
- サムネイル画像
- 「GitHub」ボタン（リポジトリへのリンク）

動画IDが分かる場合は「動画を見る」ボタンも自動的に表示され、クリックするとブラウザでニコニコ動画の視聴ページが開きます。ローカルファイル等で動画IDが判別できない場合はこのボタンは表示されません。

**注意点**

- Discordデスクトップアプリ（ブラウザ版は不可）が起動している必要があります
- リンクボタンは自分のプロフィール画面には表示されず、フレンド等の別ユーザーから見たときのみ表示されます（Discord側の仕様）
- 再生・一時停止・シーク・速度変更のたびに表示内容が更新されます

## Webhook通知（Discord / Slack）

ダウンロードの完了・失敗を、DiscordまたはSlackのチャンネルに自動投稿する機能です。

1. Discord/SlackでWebhook URLを発行します
2. 設定の「Webhook通知」欄にそのURLを貼り付けます
3. URLのドメイン（`discord.com`/`discordapp.com` または `slack.com`）から自動的にどちらのサービスか判別し、それぞれに適した形式（Discordは色付きEmbed、Slackはテキストメッセージ）で投稿します

通知するタイミング（ダウンロード完了時／失敗時）はそれぞれ個別にON/OFFできます。送信に失敗してもダウンロード処理自体には影響しません。
