# プライバシー

NNDD-RE が、あなたのPCに保存するデータと、外部に送る情報をまとめたページです。外部への送信は、使う機能を有効にしたときだけ行われます。

## 通信する先

- **ニコニコ動画・ニコニコ生放送**: 動画や番組の取得、検索、ログインなど、アプリの基本機能のために通信します
- **GitHub**: 次の場合に通信します
  - アップデートの確認とダウンロード
  - GitHub同期（設定でログインしたときだけ）
  - yt-dlp、FFmpeg、Tailscale 用のツールを、アプリ内から導入するとき
- **匿名の利用統計の受信サーバー**: 同意したときだけ通信します（次の節を参照）
- **Discord / Slack**: Webhook 通知を設定したときだけ、指定したURLに送ります。Rich Presence は、PC上の Discord アプリにだけ情報を渡します

## 匿名の利用統計

どの機能がよく使われているかを知るために、匿名の利用統計を送ることができます。

- **初期状態では何も送りません。** 初回の起動時にダイアログが表示され、「送信する」を選んだときだけ送信します。送信する内容が増えたときは、あらためて確認します
- 設定 → 情報・更新の「匿名の利用統計」で、いつでもオフにできます。オフにした時点で、送信が止まります
- 送る内容
  - アプリのバージョン、OSの種類とバージョン、言語
  - 使った機能の種類と回数（開いたタブ、動画の再生やダウンロード、生放送の視聴など）
  - 設定の値（オン/オフ、選択肢、数値だけ。GitHub同期を設定しているかどうかを含みます。パスやURL、アカウント情報は含みません）
  - 端末ごとに作る、匿名のランダムなID
  - 1時間ごとの、おおよその起動時間
- 使った機能は操作のたびには送らず、10分ごとか次の起動時にまとめて送ります
- 送らない内容: 動画ID、タイトル、検索語、コメントの中身、ファイルのパス、URL、ホスト名、ニコニコのアカウント情報
- 「送信内容を見る」で、実際に送られる内容を確認できます
- 「匿名IDを作り直す」で、匿名IDを新しいものに切り替えられます。同意をオフにすると、IDは削除されます

## ログイン情報

- ニコニコ動画のログイン状態を保つための情報は、このPC内に保存されます
- **パスワードは、初期状態では保存しません。** ログイン画面で「パスワードを保存して次回から自動ログイン」にチェックしたときだけ、OSの暗号化機能で保護して保存します
- 設定 → 全般の「ブラウザでログイン」を使うと、パスワードはアプリに保存されません
- 設定 → 全般の「視聴履歴を残さない」をONにすると、ログイン情報を送らずにゲストとして動画にアクセスします。ニコニコ側のアカウントの視聴履歴には残りません

## ローカルに保存されるデータ

- ダウンロードした動画、コメント、サムネイル、動画の情報ファイル
- ライブラリのデータベース: 動画の一覧、再生履歴、ニコ動履歴の取得結果、マイリスト、NGリスト、保存検索、自動ダウンロードの設定、プレイリスト
- アプリの設定、ログファイル、画像のキャッシュ

保存先は、設定 → 情報・更新の「パス情報」で確認できます。

## GitHub同期で送られる内容

GitHub同期を使うと、あなたのGitHubアカウントの**非公開のGist**に、設定のバックアップを保存します。

- 保存する範囲は、プロファイルごとに選べます（アプリ設定、NGリスト、マイリスト一覧、スケジュール、保存検索、プレイリスト、視聴履歴）。視聴履歴は、初期状態では含みません
- ニコニコのログイン情報、保存先のパスなど、このPC固有の設定は含みません
- 非公開のGistは、URLを知っている人であれば開けます。URLを他人に教えないでください
- GitHubにログインするときは、アカウントのパスワードを入力しません。ブラウザで承認する方式です

## Discord連携で送られる内容

- **Rich Presence**（初期状態はオフ）: 「NNDD-REで視聴中」という表示を、PC上の Discord アプリに渡します。動画のタイトル、サムネイル、GitHub へのリンクボタンは、設定で個別に選べます。このほかに、動画の視聴ページへのリンクボタン（「動画を見る」。生放送では「生放送を見る」）も付きます
- **Webhook 通知**（初期状態はオフ）: ダウンロードの完了や失敗を、指定した Discord または Slack のURLに送ります。内容は、動画のタイトルまたはエラーメッセージと、ニコニコ動画の視聴ページのURLです

## 内蔵HTTPサーバー

内蔵HTTPサーバーは、初期状態では動いていません。起動した場合も、初期状態では**このPCからのアクセスだけ**を受け付けます。

「LAN内の他端末からのアクセスを許可」や Tailscale を選ぶと、他の端末からもアクセスできます。この場合、**ログインやパスワードによる認証はありません**。信頼できるネットワークでだけ使ってください。詳しくは[内蔵HTTPサーバー・LAN共有](/NNDD-RE/http-server-integration/)を参照してください。
