# ライブラリタブ

ダウンロード済みの動画をローカルで管理するタブです。

## 表示形式

右上のツールバーにある「⊞」/「☰」ボタンでテーブル表示とグリッド表示を切り替えられます。開いたときの初期の表示形式は、設定の「ライブラリ」にある「ライブラリ表示形式」で選べます。

- **テーブル表示**: お気に入り・サムネイル・タイトル・時間・再生数（このアプリでの再生回数）・投稿日・操作ボタンの列で一覧表示
- **グリッド表示**: サムネイルを大きく並べる表示。★/☆ボタンとバッジがサムネイル上に重なります

音声のみダウンロードした動画には「♪ 音声のみ」バッジが付きます。

## ソート

テーブル表示のヘッダー（タイトル・時間・再生数・投稿日）をクリックするとその列でソートされ、もう一度クリックすると昇順/降順が切り替わります。ライブラリを開いたときの初期ソートは、設定の「ライブラリ」にある「ライブラリデフォルトソート」（ソートカラム・並び順。初期値は投稿日の昇順。カラムには「DL日」も選べます）で決まり、リスト表示・グリッド表示の両方に適用されます。

## フォルダとタグ

左側には「フォルダ」「タグ」「コメントのみ」の3つのタブがあります。

「フォルダ」タブでは、ライブラリ配下のサブフォルダごとに動画を絞り込めます。「+ フォルダ追加」から新規フォルダを作成し、動画をドラッグ&ドロップで移動できます（Ctrl/Shiftクリックで複数選択してまとめて移動も可能）。フォルダの名前は、ダブルクリックするか、行にマウスを合わせて「✎」を押すと変更できます。フォルダ自体もドラッグ&ドロップで別のフォルダの中に移動でき、「すべて」の行にドロップするとライブラリの直下に戻せます。名前の変更や移動をすると、中の動画ファイルも実際にその場所へ移ります。フォルダの削除（行にマウスを合わせて「🗑」）は中の動画ファイルごと削除されるため注意してください。

「タグ」タブでは、動画に付いているタグ（ダウンロード時のメタ情報から自動抽出）ごとに、件数の多い順で絞り込めます。上部の入力欄でタグを絞り込めます（スペース区切りでAND）。「フォルダ」タブでフォルダを選んでいるときは、そのフォルダ内の動画のタグだけが並びます（「全体」で解除）。タグを右クリックすると、「検索」（検索タブでそのタグを検索）・「ニコニコ大百科で開く」・「タグを隠す」を選べます。隠したタグは一覧の下の「隠したタグ」から「タグを表示」で戻せます。

「コメントのみ」タブには、コメントだけを保存した項目（動画のファイルがないもの）が並びます。

設定でLANライブラリを有効にしている場合、この左側に接続中のリモートNNDD/NNDD-REのライブラリも表示されます（詳細は[内蔵HTTPサーバー・LAN共有](/NNDD-RE/http-server-integration/)を参照）。

## 検索・絞り込み

上部の検索欄（「タイトル・説明文・タグで絞り込み」）にキーワードを入力すると即座に絞り込まれます。「★ お気に入りのみ」ボタンと併用できます。

## 下部の表示

一覧の下に、登録されている項目数（絞り込み中は表示中の件数も）と、動画の保存先ドライブの空き容量を表示します。

## 動画に対してできる操作

- **再生**: 「再生」ボタンまたはダブルクリックで再生します。再生数は、動画を10秒以上再生すると増えます
- **フォルダを開く**: 「フォルダ」ボタンで、OSのファイルマネージャーでその動画の保存フォルダを開きます
- **ニコ動で開く**: 「nico」ボタンで、動画のIDから、ブラウザでニコニコ動画の視聴ページを開きます（ファイル名にIDがない動画では表示されません）
- **削除**: 動画本体・サムネイル・コメントファイル・メタ情報ファイル一式を削除します（確認ダイアログあり）
- **お気に入り切り替え**: ☆/★アイコンをクリック
- **右クリックメニュー**: 「お気に入りに追加／お気に入りから外す」のほか、ファイル名にIDがある動画では「コメント差分取得 (今コメ更新)」「コメント全件再取得」でコメントを取得し直せます（DLリストに追加されます）。「コメントのみ」タブでは「動画をダウンロード」も選べます

動画を再生すると、同じフォルダにある表示中の動画が前後移動の対象になり、プレイヤーの「フォルダ連続再生」チェックをONにすると続けて再生されます。一覧上部の「▶ 連続再生」ボタンでは、現在表示している一覧（絞り込み後のすべての動画）を、順に再生できます。選択中の動画があれば、その動画から始まります。ボタン横の▼メニューから、音声のみの連続再生も選べます。

## ライブラリの更新

ライブラリタブを最初に開いたとき、動画が1件も登録されていなければ、「今すぐスキャンしますか」と確認します（アプリを起動して一度だけ表示します）。

「ライブラリを更新」ボタンで保存先のフォルダを調べなおし、手動で追加されたファイルの検出や、削除されたファイルの整理を行います。通常は、前回から変わっていないファイルを省略します。Shiftを押しながらボタンを押すと、すべてのファイルを調べなおします。スキャン中は進捗が表示され、「中断」ボタンで止められます。終わると「追加 〇 / 更新 〇 / 削除 〇 / 変更なし 〇」の形で結果が通知されます。

## ファイル名

NNDD-RE は、`タイトル - [sm12345].mp4` のように、動画のIDを角括弧で含むファイル名から、動画のIDとタイトルを認識します。同じフォルダにある `[sm12345][ThumbInfo].xml`（動画の情報）・`[sm12345].xml`（コメント）・サムネイル画像の情報も、一覧に反映されます。動画の情報のファイルがない動画は、ライブラリに登録されません。本家NNDDで保存した動画の扱いは、[NNDDからの移行](/NNDD-RE/migrate-from-nndd/)を参照してください。

コメントだけを保存した項目（動画のファイルがないもの）は、左側の「コメントのみ」タブに表示されます。この場合、再生の操作は表示されません。
