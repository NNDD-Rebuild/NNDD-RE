# ライブラリタブ

ダウンロード済みの動画をローカルで管理するタブです。

## 表示形式

画面右上のボタンでテーブル表示とグリッド表示を切り替えられます。

- **テーブル表示**: お気に入り・サムネイル・タイトル・時間・再生数（このアプリでの再生回数）・投稿日・操作ボタンの列で一覧表示
- **グリッド表示**: サムネイルを大きく並べる表示。★/☆ボタンとバッジがサムネイル上に重なります

音声のみダウンロードした動画には「♪ 音声のみ」バッジが付きます。

## ソート

テーブル表示のヘッダー（タイトル・時間・再生数・投稿日）をクリックするとその列でソートされ、もう一度クリックすると昇順/降順が切り替わります。

## フォルダとタグ

左側の「フォルダ」タブでは、ライブラリ配下のサブフォルダごとに動画を絞り込めます。「+ フォルダ追加」から新規フォルダを作成し、動画をドラッグ&ドロップで移動できます（Ctrl/Shiftクリックで複数選択してまとめて移動も可能）。フォルダの削除は中の動画ファイルごと削除されるため注意してください。

「タグ」タブでは、動画に付いているタグ（ダウンロード時のメタ情報から自動抽出）ごとに絞り込めます。

設定でLANライブラリを有効にしている場合、この左側に接続中のリモートNNDD/NNDD-REのライブラリも表示されます（詳細は[内蔵HTTPサーバー・LAN共有](/NNDD-RE/http-server-integration/)を参照）。

## 検索・絞り込み

上部の検索欄にタイトル・説明文・タグを対象にしたキーワードを入力すると即座に絞り込まれます。「★ お気に入りのみ」ボタンと併用できます。

## 動画に対してできる操作

- **再生**: 「再生」ボタンまたはダブルクリックで再生します。再生数は、動画を10秒以上再生すると増えます
- **フォルダを開く**: OSのファイルマネージャーでその動画の保存フォルダを開きます
- **ニコ動で開く**: 動画のIDから、ブラウザでニコニコ動画の視聴ページを開きます
- **削除**: 動画本体・サムネイル・コメントファイル・メタ情報ファイル一式を削除します（確認ダイアログあり）
- **お気に入り切り替え**: ☆/★アイコンをクリック

一覧上部の「連続再生」ボタンで、現在表示している一覧（絞り込み後のすべての動画）を、順に再生できます。ボタン横の▼メニューから、音声のみの連続再生も選べます。

## ライブラリの更新

「ライブラリを更新」ボタンで保存先のフォルダを調べなおし、手動で追加されたファイルの検出や、削除されたファイルの整理を行います。通常は、前回から変わっていないファイルを省略します。Shiftを押しながらボタンを押すと、すべてのファイルを調べなおします。

## ファイル名

NNDD-RE は、`タイトル - [sm12345].mp4` のように、動画のIDを角括弧で含むファイル名から、動画のIDとタイトルを認識します。同じフォルダにある `[sm12345][ThumbInfo].xml`（動画の情報）・`[sm12345].xml`（コメント）・サムネイル画像の情報も、一覧に反映されます。動画の情報のファイルがない動画は、ライブラリに登録されません。本家NNDDで保存した動画の扱いは、[NNDDからの移行](/NNDD-RE/migrate-from-nndd/)を参照してください。

コメントだけを保存した項目（動画のファイルがないもの）も、一覧に表示されます。この場合、再生の操作は表示されません。
