# インストール・アップデート

## 入手方法

[GitHub Releases](https://github.com/NNDD-Rebuild/NNDD-RE/releases/latest) から、お使いのOS向けのファイルをダウンロードします。

| OS | ファイル |
|---|---|
| Windows | `NNDD-RE-<バージョン>-setup.exe`（インストーラー） |
| Linux | `NNDD-RE-<バージョン>-x64.AppImage` / `.deb` / `.rpm` / `.tar.gz` |
| macOS | `.dmg`（Intel 版と Apple Silicon 版があります） |

ベータ版は、[リリース一覧](https://github.com/NNDD-Rebuild/NNDD-RE/releases)の「Pre-release」と表示されたものです。最新版のボタンからは、正式リリースだけが開きます。

インストーラーにはコード署名をしていないため、OSの警告（Windows の SmartScreen や macOS の Gatekeeper など）が表示されることがあります。

## 初回起動

初回起動時に、匿名の利用統計を送るかどうかを聞くダイアログが表示されます。「送信しない」を選んでも、機能は変わりません。送信する内容は[プライバシー](/NNDD-RE/privacy/)に書いてあります。

続けて、[使い方ガイド](/NNDD-RE/usage-guide/)に沿ってニコニコ動画にログインしてください。

## アップデート

設定 → 情報・更新 → 「アップデート」で、更新の確認方法を選べます。

- **起動時の確認**
  - 「確認する」（初期値）: 新しい版が見つかったときにダイアログで知らせます。更新するかどうかを選べます
  - 「自動更新」: 自動でダウンロードして、次回の終了時にインストールします
  - 「確認しない」: 起動時には確認しません
- **チャンネル**: 「安定版」（初期値）は正式リリースだけが対象です。「ベータ版」はベータ版も対象にします。新機能を早く試せますが、不具合が残っている可能性があります
- **更新を確認**: ボタンを押すと、その場で確認します

## 外部ツール（yt-dlp / FFmpeg）

既定の設定では、再生もダウンロードも yt-dlp と FFmpeg なしで動作します。次の設定に変えたときだけ、外部ツールが必要になります。

- 「ネイティブHLSダウンロードを優先する」をOFFにした場合: yt-dlp を使います（音声のみのダウンロードはできなくなります）
- 「mux実装」を「ffmpeg」にした場合: FFmpeg を使います（ネイティブHLSで失敗したときは yt-dlp に切り替わります）

導入は、設定 → 外部ツール・連携 → 外部ツールで行います。

- **yt-dlp**: アプリ内から導入・更新できます
- **FFmpeg**: Windows と Linux では、アプリ内から導入・更新できます。macOS では `brew install ffmpeg` などで、自分で導入してください

自分で用意した実行ファイルを使いたいときは、「参照...」で場所を指定できます。パスを空欄にすると、システムの PATH から自動で探します。

## データの保存先

- **動画・コメントなど**: 既定では `ドキュメント/NNDD-RE/library/Downloads` です。設定 → 全般の「動画の保存先」で変えられます。変えた後は、新しいダウンロード分だけが新しい場所に保存されます（既存のファイルは移動されません）
- **ライブラリの情報（データベース）**: `ドキュメント/NNDD-RE/system/` に保存されます
- そのほかの保存先は、設定 → 情報・更新の「パス情報」で確認できます。クリックするとパスをコピーできます
