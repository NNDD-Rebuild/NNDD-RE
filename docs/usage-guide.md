# 使い方ガイド

入手とインストールは[インストール・アップデート](/NNDD-RE/install/)を参照してください。本家NNDDを使っていた場合は、先に[NNDDからの移行](/NNDD-RE/migrate-from-nndd/)も確認してください。

## 1. 初回ログイン

設定 → 全般 → 「ニコニコ動画 ログイン」からログインします。

- **メールでログイン**: アプリ内でメールアドレス/電話番号とパスワードを入力します（2段階認証が設定されている場合は6桁コードの入力画面に進みます）。「パスワードを保存」にチェックすると、次回から自動でログインします
- **ブラウザでログイン**: 別ウィンドウで公式のログインページを開き、通常どおりログインします。パスワードはアプリに保存されません
- **SSOログイン**: ログイン画面の Apple / Google / LINE / X / Facebook ボタンからもログインできます（ブラウザでログインと同じ方式）

ブラウザでのログインでボット対策の確認画面が出たときは、表示されたウィンドウで操作してください。

ログインしなくても使える機能（ランキングなど）もありますが、ダウンロードや生放送の視聴にはログインが必要です。

## 2. 動画をダウンロードする

- DLリストタブで動画ID（`sm12345` など）・マイリストのURL・シリーズのURLのいずれかを入力し、「DLリストに追加」を押します（マイリストやシリーズのURLは自動で判別され、中の動画がまとめて追加されます）
- 検索・ランキング・マイリストの動画カードにある「DL」ボタンからも追加できます
- 音声のみのダウンロード、コメントのみのダウンロードも選べます
- 既定の設定では、yt-dlp や FFmpeg を入れなくてもダウンロードできます。ダウンロードした動画はライブラリに自動で登録されます。同時ダウンロード数や帯域制限などは[設定](/NNDD-RE/settings/)の「ダウンロード」を参照してください
- ダウンロードに失敗する場合は、[トラブルシューティング](/NNDD-RE/troubleshooting/)を確認してください

## 3. 動画を再生する

- ライブラリで「再生」を押すと、ダウンロード済みのファイルを再生します
- 検索・ランキング・マイリストで「再生」を押すと、ダウンロードせずにストリーミング再生します。設定 → プレイヤーの「ストリーミング再生」で、NNDD-RE の内蔵プレイヤーとニコニコ公式プレイヤーの埋め込みのどちらを使うかを選べます
- 音声のみの再生にも対応しています
- コメントは自動で動画に重ねて表示されます
- 操作の詳細は[プレイヤー](/NNDD-RE/player/)を参照してください

生放送は、生放送タブから開きます。詳しくは[生放送](/NNDD-RE/live/)を参照してください。

## 4. 自動でダウンロードする

1. 自動でダウンロードしたいマイリストを、マイリストタブに登録します（シリーズやフォロー中の投稿者を対象にする場合は、登録は不要です）
2. 設定 → スケジュール → 新規スケジュールを作ります
3. 対象、曜日、時刻を指定します

指定した時刻に、新しく追加された動画だけが自動でダウンロードされます。
