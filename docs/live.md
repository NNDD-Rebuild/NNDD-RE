# ニコニコ生放送

ニコニコ生放送の番組を、動画と同じような操作感で視聴できます。放送中の番組のほか、追っかけ再生（放送中に過去へ巻き戻して見る）とタイムシフトにも対応しています。

視聴にはニコニコのログインが必要です。コメントの投稿と、番組の録画・ダウンロードには対応していません。

## 生放送タブ

メインウィンドウの「生放送」タブから番組を探して開きます。

上部の入力欄に番組ID（`lv〜`）、チャンネルID（`ch〜`）、または生放送ページのURLを入力して「視聴」を押すと、その番組を直接開けます。

その下のサブタブで番組の一覧を切り替えます。番組カードのサムネイル・タイトル・「視聴」ボタンのクリック、またはカードのダブルクリックでプレイヤーが開きます。カードの左上には「放送中」「放送予定」「終了」の状態が表示されます。

- **フォロー中 (放送中)** — フォローしているユーザー・チャンネルの放送中の番組
- **フォロー中 (放送予定)** — フォローしているユーザー・チャンネルのこれから始まる番組（開始が近い順）
- **ランキング** — 「放送中」「放送予定」「終了（日付指定）」のランキング。公式・チャンネル番組とユーザー番組を切り替えて表示し、カード左下に順位が出ます
- **カテゴリ** — 一般・やってみた・ゲーム・動画紹介・顔出し・凸待ち・VTuber のカテゴリ別の放送中番組。来場者数やコメント数などで並べ替えられます
- **検索** — キーワードで番組を検索します。「放送中」「放送予定」「過去」と並び順を選べ、結果は100件ごとのページ送りです。タイトルや説明文に含まれる語でも一致します
- **タイムシフト予約** — タイムシフト予約済みの番組

## プレイヤー

生放送のプレイヤーは、通常の動画の[プレイヤー](/NNDD-RE/player/)と同じ画面構成です。左に映像と操作バー、右にサイドパネルが並びます。サイドパネルの境界はドラッグで幅を変えられます。

### 操作バー

再生/一時停止・音量・画質・コメント表示のON/OFF・コメントリストの表示方式の切り替え（💬 タブ / 💬 浮動）・フルスクリーンが並びます。映像をクリックしても一時停止はしません。

- **放送中** — 時間表示の位置に「LIVE」と表示されます。「最新」ボタンで最新の位置に戻れます
- **追っかけ再生に対応した番組** — シークバーで過去へ巻き戻して視聴できます。巻き戻している間は、最新からどれだけ遅れているか（`-12:34` など）が表示されます
- **タイムシフト** — 通常の動画と同じくシークバー・再生時間・再生速度が使えます

画質は解像度（`720p` など）で表示されます。「自動」を選ぶと回線の状態に合わせて画質が切り替わります。

キーボードショートカットは通常のプレイヤーと同じものが使えます（シークはタイムシフトと追っかけ再生のときのみ）。

### コメント

流れるコメントは通常の動画と同じ描画エンジンで表示され、NGリストもそのまま適用されます。

番組を開いた時点より前のコメントも、裏で自動的に取得してコメントリストに並べます。コメント数が1万件を超える番組では、全件ではなく再生している位置の前後だけを取得し、シークしたときに必要な分を追加で取得します。取得中は操作バーに「コメント取得中…」と表示されます。

### サイドパネル

- **番組情報** — タイトル、状態、開始日時、経過時間、来場者数・コメント数、放送者、タグ、説明文。放送者名のクリックでフォロー中タブにその人の動画を表示し、右クリックでユーザーページを開けます。タグはダブルクリックで生放送タブの検索を実行します。説明文中の生放送の番組リンクは生放送プレイヤーで開きます
- **コメントリスト** — 通常のプレイヤーと同じコメント一覧です。再生位置に合わせて自動でスクロールし、並べ替え・絞り込み・右クリックでのNG追加ができます。タイムシフトと追っかけ再生では、行をクリックするとその時刻へ移動します
- **お知らせ** — 運営コメント、ギフト、ニコニ広告などの通知

運営コメントは映像の上部にも表示されます。

### コメントリストの浮動ウィンドウ

コメントリストは、サイドパネルのタブの代わりに独立したウィンドウ（浮動ウィンドウ）で表示することもできます。操作バーの「💬 タブ / 💬 浮動」ボタンで切り替えられます。浮動ウィンドウは最前面に固定するかどうかを選べ、位置と大きさは次回も引き継がれます。浮動ウィンドウを閉じるとサイドパネルのタブ表示に戻ります。

## タイムシフト

終了した番組でタイムシフトが公開されている場合は、タイムシフトで視聴できます。

予約していない、または予約したがまだ視聴を開始していない番組を開くと、プレイヤーに「タイムシフトを予約して視聴開始」ボタンが表示されます。このボタンを押したときだけ予約と視聴開始を行います。**視聴を開始すると視聴期限のカウントが始まり、取り消せません。** タイムシフトの視聴条件（プレミアム会員であることなど）はニコニコ生放送側の仕様に従います。

## 設定

設定の「生放送」タブで次の項目を変更できます。詳しくは[設定](/NNDD-RE/settings/)を参照してください。

- **別の番組を新しいウィンドウで開く** — OFF（初期値）の場合、開いている生放送プレイヤーで番組を切り替えます。同じ番組は設定に関わらず1つのウィンドウでしか開きません
- **コメントリストの表示方式** — タブ表示（初期値）または浮動ウィンドウ
- **コメントウィンドウを最前面に表示する** — 浮動ウィンドウを常に手前に表示します（初期値ON）

## 外部からの起動

`nndd-re-cmd://live/lv123456789` の形式のURLを開くと、その番組を生放送プレイヤーで開きます。
