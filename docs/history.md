# 履歴・統計

## 履歴タブ

視聴履歴を確認するタブです。「アプリ内履歴」と「ニコ動履歴」の2つを切り替えて見られます。

### アプリ内履歴

このアプリで実際に再生した動画の記録です。10秒以上再生した動画だけが記録されます（読み込み待ちなど、再生に至らなかったものは記録されません）。新しい順に直近1000件が表示されます。

各行には、次の内容が表示されます。

- タイトル（前回の再生位置が保存されている場合は「● 続きから (XX%)」と表示）
- 動画ID
- 視聴日時
- ローカル再生かどうか（○マーク）
- 操作: 「▶」ボタン（再生）、「ニコ動で開く」ボタン（ブラウザでニコニコ動画の視聴ページを開く）

行をダブルクリックしても再生できます。行を右クリックすると、「再生」「ニコニコ動画で開く」「履歴から削除」（その履歴だけを削除）を選べます。「履歴を全消去」で、アプリ内履歴をまとめて削除できます。

#### 実際に視聴した時間

再生を始めてから終わる（別の動画への切り替え、ウィンドウを閉じる、アプリの終了）までの時間から、一時停止していた時間を引いて、実際に視聴した秒数を記録します。この秒数は、統計の「総再生時間」に集計されます。

#### 続きから再生

再生位置が30秒以上に達した動画は、再生位置が5秒おきに保存されます。設定の「プレイヤー」にある「続きから再生する」（初期値はOFF）がONのときは、次に開いたときに続きから再生されます。動画の残りが15秒を切るところまで進んでいた場合は、「見終わった」とみなされ、保存した位置は消えます。音声のみで再生しているときは、再生位置は保存されません。

### ニコ動履歴

ニコニコ動画のアカウントの視聴履歴です。アプリの起動時に、自動で、新しい分を取得します。「更新」ボタンを押すと、ニコニコ動画側の履歴を全件読み直し、ブラウザなどで削除された項目もこのアプリの一覧から消えます。新しい順に最大3000件が表示されます。ニコ動履歴は、ニコニコのアカウントごとに分かれています。アカウントを切り替えると、そのアカウントの履歴が表示されます。

行をダブルクリックすると再生できます。行を右クリックして「ニコ動履歴から削除」を選ぶと、ニコニコ動画側の履歴からも削除します。「履歴を全消去」で消えるのは、アプリ内履歴だけです。ニコ動履歴は消えません。

ログインしていない場合は、「ニコ動履歴はありません。ニコニコ動画にログインしていない可能性があります。」と表示されます。

### 再生済みバッジ

ランキング・検索・フォロー中・マイリストの動画に表示される「視聴済み」のバッジ（👁）は、アプリ内履歴とニコ動履歴のどちらかに記録があれば表示されます。他の端末やブラウザで見た動画にも、バッジが付くのは、このためです。表示のON/OFFは、設定 → 表示・検索の「ランキング・フォロー中・マイリストに再生済みバッジを表示する」で切り替えられます。

## 統計

ライブラリと視聴履歴を集計して表示する、ダッシュボードのタブです。期間を指定することはできません。

### サマリーカード

- **ライブラリ動画数**: ダウンロード済みの動画の総数
- **お気に入り数**: [ライブラリ](/NNDD-RE/library/)でお気に入りにした動画の数
- **総再生時間**: 履歴に記録された、実際に視聴した秒数の合計（直近1000件の履歴が対象です）
- **総再生回数**: ライブラリにある動画の再生回数の合計（10秒以上再生するたびに、1回と数えます）。ライブラリから削除した動画の再生回数は含まれません

### 月別ダウンロード数

直近12か月について、月ごとのダウンロード件数を、棒グラフで表示します。集計の基準は、ダウンロードした日時です（視聴した日時ではありません）。ダウンロードではなく、ライブラリの更新で取り込んだファイルは、ファイルの作成日時で集計します。

### 日別視聴数

直近7日間について、日ごとに視聴した動画の件数を、棒グラフで表示します。同じ動画を何度も視聴したときは、そのたびに数えます。直近1000件の履歴が対象です。

### タグ別動画数トップ10

ライブラリの動画に付いているタグを集計して、件数が多い順に、上位10個を表示します。1本の動画に複数のタグが付いている場合は、それぞれのタグで数えます。
