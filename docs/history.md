# 履歴タブ

視聴履歴を確認するタブです。「アプリ内履歴」と「ニコ動履歴」の2つを切り替えて見られます。

## アプリ内履歴

このアプリで実際に再生した動画の記録です。10秒以上再生した動画だけが記録されます（読み込み待ちなど再生に至らなかった分は記録されません）。

各行には以下が表示されます。

- タイトル（前回の再生位置が保存されている場合は「● 続きから (XX%)」と表示）
- 動画ID
- 視聴日時
- ローカル再生かどうか（○マーク）
- 操作: 再生（ローカル動画ならローカルファイルから、それ以外はストリーミングで再生）、ニコニコで開く

「履歴を全消去」でアプリ内履歴をまとめて削除できます。

### 実視聴時間の計測

再生を開始してから終了する（別動画への切り替え・ウィンドウを閉じる・アプリ終了）までの経過時間から、一時停止していた時間を差し引いて実際に視聴した秒数を計測しています。シークして早送りした分もそのまま経過時間としてカウントされます。この実視聴秒数は[統計タブ](/NNDD-RE/stats/)の「総再生時間」に集計されます。

### 続きから再生（レジューム）

30秒以上視聴した動画は5秒おきに再生位置が保存され、次に開いたときに続きから再生されます。動画の残り15秒を切った時点まで進んでいた場合は「見終わった」とみなされ、保存位置はクリアされます。

## ニコ動履歴

ニコニコ動画本家のアカウント視聴履歴です。アプリ起動時に自動で差分取得され、このアプリからは削除できません（参照専用）。ログインしていない場合は「ニコ動履歴はありません。ニコニコ動画にログインしていない可能性があります。」と表示されます。

## 再生済みバッジについて

ランキング・検索・フォロー中・マイリストの動画サムネイルに表示される「視聴済み」バッジは、アプリ内履歴・ニコ動履歴のどちらかに記録があれば表示されます。他の端末やブラウザで視聴した動画にもバッジが付くのはこのためです。表示のON/OFFは設定の「視聴履歴: 再生済みバッジ表示」で切り替えられます。
