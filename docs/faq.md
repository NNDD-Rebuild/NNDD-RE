# よくある質問

不具合の対処は[トラブルシューティング](/NNDD-RE/troubleshooting/)にまとめています。

## 全般

### NNDD-RE は本家NNDDの新バージョンですか？

いいえ。NNDD-RE は、本家NNDD（Adobe AIR版）を Electron で一から作り直した、別のアプリです。本家NNDDとの互換性を目指しているため、「精神的後継」と呼んでいます。経緯は[トップページ](/NNDD-RE/)を参照してください。

### 本家NNDDで保存した動画や設定を使えますか？

使えます。本家NNDDで保存した動画のフォルダは、「動画の保存先」に指定すると読み込めます（動画の情報ファイルがない動画を除きます）。設定、マイリスト、履歴などは、インポート機能で取り込めます。手順は[NNDDからの移行](/NNDD-RE/migrate-from-nndd/)を参照してください。

### 対応しているOSは？

Windows、Linux、macOS です。入手方法は[インストール・アップデート](/NNDD-RE/install/)を参照してください。

### ログインしなくても使えますか？

ランキングなど、ログインなしで見られる機能もあります。ダウンロードや生放送の視聴には、ニコニコ動画のログインが必要です。

### 利用状況のデータは送られますか？

初期状態では、何も送りません。初回の起動時のダイアログで同意したときだけ、匿名の統計を送ります。詳しくは[プライバシー](/NNDD-RE/privacy/)を参照してください。

## ダウンロード

### yt-dlp や FFmpeg は必要ですか？

既定の設定では、必要ありません。設定で「ネイティブHLSダウンロードを優先する」をOFFにしたときは yt-dlp が、「mux実装」を「ffmpeg」にしたときは FFmpeg が必要です。詳しくは[インストール・アップデート](/NNDD-RE/install/)を参照してください。

### ダウンロードした動画は、どこに保存されますか？

既定では `ドキュメント/NNDD-RE/library/Downloads` です。設定 → 全般の「動画の保存先」で変えられます。

### マイリストの新着を、自動でダウンロードできますか？

できます。設定 → スケジュールで、対象と曜日・時刻を指定します。マイリストのほか、シリーズやフォロー中の投稿者も対象にできます。詳しくは[DLリスト](/NNDD-RE/download/)を参照してください。

### コメントだけを保存できますか？

できます。動画カードの「DL」ボタン横の▼メニューから、「コメントのみ」を選びます。ダウンロード済みの動画で「DL」ボタンを押すと、コメントだけを取得します。

## 生放送

### 追っかけ再生ができません

追っかけ再生（放送中に過去へ巻き戻して見る機能）は、ニコニコのプレミアム会員だけが使えます。一般会員やログインしていない場合は、通常の放送中の表示になります。

### 生放送にコメントを投稿できますか？

できません。コメントの表示だけに対応しています。

### 生放送を録画できますか？

放送中の番組の録画、放送予定の番組の録画予約、タイムシフトの保存に対応しています。詳しくは[生放送](/NNDD-RE/live/)を参照してください。

## 連携

### スマホから、ライブラリを見られますか？

設定 → 全般の「内蔵HTTPサーバー」を起動して、「待受範囲」を「LAN内の他端末からのアクセスを許可」にすると、同じネットワーク内のスマホのブラウザから見られます。外出先から見たい場合は Tailscale を使います。詳しくは[内蔵HTTPサーバー・LAN共有](/NNDD-RE/http-server-integration/)を参照してください。

### 複数のPCで、設定を同じにできますか？

GitHub同期で、設定、NGリスト、マイリストなどを共有できます。詳しくは[GitHub同期・バックアップ](/NNDD-RE/github-sync/)を参照してください。
