# 統計タブ

ライブラリと視聴履歴を集計して表示するダッシュボードです。タブを開くたびにその場で再集計されるため、常に最新の状態が表示されます（自動更新や期間指定はありません）。

## サマリーカード

- **ライブラリ動画数**: ダウンロード済み動画の総数
- **お気に入り数**: [ライブラリ](/NNDD-RE/library/)でお気に入り登録した動画数
- **総再生時間**: [履歴](/NNDD-RE/history/)に記録された実視聴秒数の合計
- **総再生回数**: 各動画の再生回数（10秒以上再生するたびに1回カウント）の合計

## 月別ダウンロード数

直近12ヶ月について、月ごとのダウンロード件数を棒グラフで表示します。集計基準はダウンロードした日時（視聴日時ではありません）です。

## 日別視聴数

直近7日間について、日ごとに視聴した動画の件数を棒グラフで表示します。同じ動画を複数回視聴した場合はその都度カウントされます。

## タグ別動画数トップ10

ライブラリ内の動画に付いているタグを集計し、件数が多い順に上位10個をプログレスバーで表示します。1本の動画が複数タグを持つ場合、それぞれのタグでカウントされます。
