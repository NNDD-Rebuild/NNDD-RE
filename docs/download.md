# DLリストタブ

ダウンロードキューの追加・進捗確認・管理を行うタブです。

## キューへの追加

入力欄に以下のいずれかを入力し、「DLリストに追加」（またはEnter）で追加します。

- 動画ID（`sm12345`等）または視聴ページURL → その動画1件を追加
- マイリストURL/ID → マイリスト内の全動画を一括取得して追加（取得中は「マイリスト取得中…」と表示）
- シリーズURL/ID → シリーズ内の全動画を一括取得して追加

マイリスト/シリーズは自動検出されるため、通常ダウンロードしたい動画のURLをそのまま貼り付ければ問題ありません。取得に失敗した場合はエラーメッセージが表示されます。

他のタブ（ランキング・検索・フォロー中・マイリスト）の動画カードから「DL」ボタンで直接追加することもできます。

## ダウンロード種別

- **通常ダウンロード**: 動画ファイル＋コメント（全量）＋サムネイル＋メタ情報を取得します。既定設定（ネイティブHLS優先＋mediabunny mux）なら yt-dlp / FFmpeg は不要です。対応できない動画のみ自動でyt-dlpにフォールバックします（詳細は[トラブルシューティング](/NNDD-RE/troubleshooting/)を参照）
- **音声のみダウンロード**: 映像を含まない音声ファイル（.m4a）のみ取得します。動画カードのDLボタン横の▼メニューから選べます
- **コメントのみダウンロード**: 動画ファイルを取得せず、コメントとメタ情報のみ取得します。既にダウンロード済みの動画に対して「DL」ボタンをもう一度押すと自動的にこのモードになります

## キューの状態

一覧はテーブル形式で、状態・動画名・進捗（プログレスバー＋%）・詳細メッセージ・操作ボタンが並びます。

主な状態: 待機中 → 視聴ページ取得 → コメント取得 → サムネ取得 → （動画取得: プレイリスト解析→鍵取得→セグメントDL→結合中、またはyt-dlpでの動画取得）→ 完了。エラー時は失敗、ユーザーが中断した場合はキャンセルになります。

## キューの操作

- **キャンセル**: 実行中・待機中の項目を中止します
- **リトライ**: 失敗・キャンセルした項目を再度キューに戻します（自動リトライも設定回数まで行われます）
- **削除**: 完了・失敗・キャンセル済みの項目を一覧から消します（ファイル自体は残ります）
- **完了済みをクリア**: 成功・スキップ済みの項目をまとめて削除します
- **全キャンセル**: 確認ダイアログの後、実行中・待機中すべてを中止します

同時に実行されるダウンロード数は設定の「同時ダウンロード数」（デフォルト2）に従い、それを超える分は順番に待機します。

## 自動追加（スケジュール）

設定のスケジュールタブで、マイリストと曜日・時刻を指定しておくと、その時刻に自動でマイリストの新着動画をチェックし、未ダウンロードの動画だけをこのキューに自動追加します。1分おきにチェックが走り、アプリが停止していて実行時刻を過ぎていた場合は次回起動時に即座に実行されます。
