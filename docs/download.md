# DLリストタブ

ダウンロードキューの追加・進捗確認・管理を行うタブです。

## キューへの追加

入力欄に以下のいずれかを入力し、「DLリストに追加」（またはEnter）で追加します。

- 動画ID（`sm12345`等）または視聴ページURL → その動画1件を追加
- マイリストのURL（`.../mylist/12345`） → マイリスト内の全動画を一括取得して追加（取得中は「マイリスト取得中…」と表示）
- シリーズのURL（`.../series/12345`） → シリーズ内の全動画を一括取得して追加
- 投稿者ページのURL（`https://www.nicovideo.jp/user/1234567`） → その投稿者の投稿動画を一括取得して追加
- 生放送のID（`lv12345`）またはURL → その番組のタイムシフトのダウンロード。確認ダイアログで了承すると追加されます（未予約・未視聴の場合は、予約と視聴開始を自動で行います。視聴開始すると視聴期限のカウントが始まり、取り消せません）

マイリスト/シリーズ/投稿者ページは入力内容から自動検出されるため、通常ダウンロードしたい動画のURLをそのまま貼り付ければ問題ありません。マイリストやシリーズは、IDだけでなくURLで入力してください。取得に失敗した場合はエラーメッセージが表示されます。

他のタブ（ランキング・検索・フォロー中・マイリスト）の動画カードから「DL」ボタンで直接追加することもできます。入力欄に、URLをドラッグ&ドロップして追加することもできます。DLリストのタブを開いて、入力欄以外の場所で Ctrl+V を押すと、コピーしてある動画のURL・動画ID・生放送のID/URL・マイリストのURLが、そのまま追加されます（複数行も追加できます）。マイリスト・シリーズ・投稿者ページのURLを入力欄に入れると「サブフォルダを作成」のチェックボックスが現れ、チェックすると、そのマイリスト名・シリーズ名・投稿者名のフォルダに保存します。

## ダウンロード種別

- **通常ダウンロード**: 動画ファイル、コメント、サムネイル、動画の情報を取得します。既定の設定では yt-dlp / FFmpeg は不要です（外部ツールが必要になる設定は、[トラブルシューティング](/NNDD-RE/troubleshooting/)を参照）
- **音声のみダウンロード**: 映像を含まない音声ファイルだけを取得します。動画カードの「DL」ボタン横の▼メニューから選べます
- **コメントのみダウンロード**: 動画ファイルは取得せず、コメントと動画の情報だけを取得します。ダウンロード済みの動画で「DL」ボタンを押すと、このモードになります
- **コメントの再取得**: ダウンロード済みの動画の▼メニューから、新しく付いたコメントだけを追加で取得する「コメント差分取得」と、全件を取り直す「コメント全件再取得」を選べます

## キューの状態

一覧はテーブル形式で、状態・動画名・進捗（プログレスバー＋%）・詳細メッセージ・操作ボタンが並びます。

主な状態: 待機中 → 視聴ページ取得 → コメント取得 → 投コメ取得 → サムネ取得 → 動画取得（セグメントDL・結合中などを含む）→ 完了。エラー時は失敗、ユーザーが中断した場合はキャンセルになります。一時停止した項目は「一時停止中」と表示されます。音声のみ・コメントのみ・コメント差分・録画の項目には、動画名の横にそれぞれ「♪ 音声のみ」「💬 コメントのみ」「💬 コメント差分」「● 録画」のバッジが付きます。

## 下部の表示

一覧の下に、「DL済み 〇 項目, 未DL 〇 項目, 〇GB 空き」を表示します。「DL済み」はキュー内の完了・スキップ済みの項目の数、「未DL」はそれ以外の項目の数です。空き容量は、動画の保存先があるドライブのものです。

## キューの操作

- **一時停止 / 再開**: 実行中・待機中の項目ごとの「一時停止」ボタン（一時停止中は「再開」）のほか、一覧の上部の「全て一時停止」から、すべてをまとめて一時停止できます（一時停止中の項目があるときは、同じボタンが「全て再開」になります）
- **キャンセル**: 実行中の項目を中止します
- **リトライ**: 失敗・キャンセルした項目を再度キューに戻します（自動リトライも設定回数まで行われます）
- **削除**: 実行中でない項目（待機中・完了・失敗・キャンセル済みなど）を一覧から消します（ファイル自体は残ります）
- **完了済みをクリア**: 成功・スキップ済みの項目をまとめて削除します
- **全キャンセル**: 確認ダイアログの後、実行中・待機中すべてを中止します

同時に実行されるダウンロード数は設定の「同時ダウンロード数」（デフォルト2）に従い、それを超える分は順番に待機します。

## 生放送の録画

放送中の番組を録画しているときは、キューに「● 録画」のバッジが付きます（放送開始から録画する場合は「● 録画 (最初から)」）。録画中の項目には進捗バーは出ません。録画は、「録画停止」で止められます（それまでの録画は保存されます）。録画、録画予約、タイムシフトの保存の方法は、[生放送](/NNDD-RE/live/)を参照してください。

## 自動ダウンロード（スケジュール）

設定 → ダウンロード → スケジュールで、対象と曜日・時刻を指定しておくと、その時刻に新着動画を確認して、未ダウンロードの動画だけを、このキューに自動で追加します。

- **対象**: マイリスト、シリーズ、フォロー中の投稿者から選べます。マイリストタブへの事前の登録は、マイリストを対象にするときだけ必要です
- **曜日・時刻**: 曜日は複数選べます（初期値は月曜〜金曜、時刻は 03:00）
- **対象の名前でフォルダを作成して保存**: ONにすると、マイリスト名・シリーズ名・投稿者名のフォルダに保存します（初期値はOFF）
- **有効 / 無効**: スケジュールごとに切り替えられます
- スケジュールはニコニコのアカウントごとに分かれており、そのとき使用中のアカウントの分だけが実行されます（[マイリスト](/NNDD-RE/mylist/)の「アカウントごとの管理」を参照）

アプリを起動している間、1分おきに時刻を確認します。一度でも実行したことのあるスケジュールは、アプリを停止している間に実行時刻を過ぎていた場合、次の起動時に1回だけ実行します（作成してから一度も実行していないスケジュールは、設定した時刻にアプリが起動していないと実行されません）。
