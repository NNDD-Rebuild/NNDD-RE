# 設定リファレンス

設定画面は左側のタブで11個（+開発者モード時のみ「デバッグ」）に分かれています。各項目が実際に何をするものかを説明します。

## 全般

**動画の保存先**
: ダウンロードした動画・コメントファイルの保存先フォルダです。デフォルトは `Documents/NNDD-RE/library/Downloads`。「参照...」で任意のフォルダに変更できます（外付けドライブやNAS上のフォルダも指定可能）。変更後は新規ダウンロード分のみ新しい場所に保存され、既存ファイルは移動されません。

**ニコニコ動画 ログイン**
: 3つの方法があります。
  - *メールでログイン*: アプリ内のフォームにメールアドレス/電話番号とパスワードを入力してログインします。2段階認証が設定されているアカウントでは、続けて6桁の認証コード入力を求められます。「パスワードを保存」にチェックすると、次回起動時にパスワード入力なしで自動ログインします。
  - *ブラウザでログイン*: 別ウィンドウで公式のログインページを開き、そこでログインするとCookieがNNDD-REに引き継がれます。パスワードがアプリに保存されないため、共有PC等で使う場合に向いています。
  - *SSOログイン*: Apple / Google / LINE / X / Facebookのアカウントでログインします（ブラウザでログインと同じ別ウィンドウ方式）。
  ブラウザ経由のログインはボット対策（Cloudflare Turnstile）に阻まれることがあるため、内部的に「API直叩き→隠しウィンドウでの自動解決→表示ウィンドウでの手動操作」の順に自動でフォールバックします。手動操作が必要な場合のみウィンドウが表示されます。

**プライバシー: 視聴履歴を残さない**
: ONにすると、動画の再生・ダウンロード時にログインCookieを送らずゲスト扱いでアクセスするようになります。ニコニコ動画側のアカウント視聴履歴に一切残したくない場合に使います。副作用として、年齢制限動画やチャンネル会員限定動画はログインが必要なため視聴・ダウンロードできなくなることがあります。ONにするとその場合の挙動をさらに選べます: 「毎回確認する」（都度ダイアログで聞く）、「常に履歴を残して再生する」（その動画だけログイン状態でアクセス）、「常に再生しない」（スキップ）。

**視聴履歴: 再生済みバッジ表示**
: ランキング・フォロー中・マイリストの動画サムネイルに「視聴済み」バッジを表示するかどうかです。判定には、このアプリ内で再生した記録と、ニコニコ動画本家の視聴履歴（起動時に自動取得）の両方を使うため、他の端末やブラウザで観た動画にもバッジが付きます。

**内蔵HTTPサーバー**
: NNDD-RE内にHTTPサーバーを立ち上げ、スマホや他のPCのブラウザからライブラリを閲覧・再生できるようにする機能です。「起動」を押すと `http://127.0.0.1:<ポート>/library` で待受を開始し、QRコードでスマホからすぐアクセスできます。
  - *LAN内からのアクセスを許可*: デフォルトではPC自身（localhost）からしかアクセスできません。ONにすると同じLAN内の他端末（スマホ等）からもアクセスできるようになります。認証機構は無いため、信頼できるネットワーク内でのみ有効にしてください。ファイアウォールでポートをブロックされている場合は別途受信規則の許可が必要です。
  - *起動時に自動起動する*: NNDD-RE起動のたびに手動で「起動」を押さなくてもサーバーが立ち上がるようにします。
  - *ポート*: 待受ポート番号（デフォルト12345）。変更はサーバー再起動後に反映されます。
  - *動画ファイルのストリーミング配信を許可*: OFFにすると `/api/video/:id/stream` 等の動画本体を配信するエンドポイントが無効になり、ライブラリ情報の閲覧のみ許可される状態になります。動画の実体まで他人に見せたくない場合はOFFにします。
  - *マイリスト情報の共有を許可*: `/api/mylist` 経由でのマイリスト情報取得を許可するかどうかです。

**LANライブラリ（リモートNNDD参照）**
: 同じLAN上で動いている別のNNDD-RE（または本家NNDD）の内蔵HTTPサーバーに接続し、そちらのライブラリを「LANライブラリ」タブから閲覧・再生できるようにする機能です。接続先のIPアドレスとポート（本家NNDDの初期値は12300）を指定します。接続先側でも内蔵HTTPサーバー（本家では「サーバー設定」）を有効にしておく必要があります。

**システムトレイ**
: 「トレイアイコンを表示」でタスクトレイにNNDD-REのアイコンを常駐させます。「ウィンドウを閉じたらトレイに最小化」をONにすると、×ボタンでウィンドウを閉じてもアプリ自体は終了せずダウンロードが継続します。完全に終了したいときはトレイアイコンから終了を選ぶ必要があります。

**ウィンドウの大きさ・位置をリセットする**
: ウィンドウが画面外に出てしまった、極端に小さくなった等の際に、サイズ1280×800・最大化解除の初期状態に一括で戻すボタンです。

**画像キャッシュ（サムネイル・アイコン）**
: 動画のサムネイルや投稿者アイコンをローカルに保存しておく機能です。一度表示した画像は次回オフラインでも表示でき、通信量も減ります。上限サイズ（MB）を超えると古いものから削除されます（0を指定すると無制限）。「キャッシュを削除」で全消去できますが、次回表示時に再ダウンロードが発生します。

**Discord連携（Rich Presence）**
: Discordデスクトップアプリを起動している状態でONにすると、自分のDiscordプロフィールの「アクティビティ」欄に今NNDD-REで再生中の動画情報が表示されます。動画タイトル・経過時間・サムネイル・GitHubリンクボタンをそれぞれ個別に表示するか選べます。リンクボタンは自分のプロフィール画面には表示されず、フレンド等の別ユーザーから見たときのみ表示されるというDiscord側の仕様があります。

**Webhook通知（Discord / Slack）**
: ダウンロードの完了・失敗をDiscordやSlackのチャンネルに自動投稿する機能です。各サービスのWebhook URLを1つ貼り付けるだけで、URLのドメインから自動でDiscord/Slackいずれかの投稿形式を判別して送信します。通知するタイミング（完了時／失敗時）は個別にON/OFFできます。

**開発者オプション**
: ONにすると設定タブの一覧に「デバッグ」が追加されます。通常の利用では不要ですが、APIレスポンスの内容を調べたい場合やバグ報告のために生データを取得したい場合に使います。

## ランキング・検索・マイリスト

**デフォルト表示**
: ランキング・検索・マイリストの一覧をグリッド（サムネイル大きめ）表示にするか、リスト（コンパクトな一覧）表示にするかの初期値です。開いた後でも画面上部のボタンで都度切り替えられます。

**センシティブな動画を隠す**
: デフォルトON。OFFにすると、ニコニコ動画側でR18等の閲覧注意フラグが付いた動画もランキングや検索結果にそのまま表示されるようになります。

**検索API**
: 検索タブで使うAPIを選びます。「スナップショット」（デフォルト）は日次更新のため新着動画が検索結果に出るまで最大1日程度かかりますが、タグ完全一致検索の精度が高めです。「nvapi（即時反映）」は投稿直後の動画もすぐ検索できますが、検索結果にタグ情報が含まれないため動画情報タブでのタグ表示ができません。

**起動時のタブ**
: NNDD-RE起動直後に表示するタブ（ランキング・検索・マイリスト・DLリスト・ライブラリ・履歴・設定のいずれか）です。ライブラリ整理から始めたい人は「ライブラリ」、常に新着チェックから入りたい人は「ランキング」等、使い方に合わせて設定します。

**テーマ**
: 画面全体の配色をダーク／ライトで切り替えます。

## DLリスト・ライブラリ

**同時ダウンロード数**
: 一度に並行してダウンロードする動画の本数（1〜10、デフォルト2）です。数値を上げると全体のダウンロード完了は早まりますが、回線帯域やニコニコ側のレート制限を圧迫しやすくなります。

**リトライ回数**
: ダウンロードが失敗したときに自動で再試行する回数です。不安定な回線やニコニコ側の一時的なエラーに対する保険になります。

**DL間クールダウン**
: 1本のダウンロード（動画取得・コメント取得含む）が終わってから、次のダウンロードを開始するまで意図的に待機する秒数です。0だと待機なしで即座に次に進みます。短時間に大量ダウンロードするとレート制限に引っかかりやすい場合、数秒〜数十秒の間隔を空けることで安定させられます。

**DL帯域制限**
: ダウンロードの通信速度上限（Mbps）です。0は無制限。yt-dlp経由・ネイティブHLS経由どちらの方式でダウンロードした場合にも適用されるため、ダウンロード中に他の通信（ビデオ会議等）を圧迫したくないときに使います。

**全コメント取得 / easyコメント取得**
: 「全コメント取得」をONにすると、新規ダウンロード時にその動画の投稿開始からの過去コメントを全件取得します（OFFだと直近の「今コメ」のみ）。「easyコメント取得」は全コメント取得時に、通常のコメントに加えて簡易投稿（easyスレッド、いわゆる増量コメント）も含めるかどうかで、ONにするとコメント数によってはダウンロード時間が大幅に伸びます。

**音声のみDL時はコメントを取得しない**
: 音声だけをダウンロードするときは通常コメントの重畳表示をしないため、デフォルトでコメント取得自体をスキップして時間を節約します。

**動画DL方式**
: 「ネイティブHLSダウンロードを優先する」をONにすると、NNDD-RE内蔵の実装でニコニコのHLSストリームを直接取得します（デフォルトON）。OFFにすると常に外部ツールのyt-dlpを使ってダウンロードします。ネイティブ実装が失敗した場合は自動的にyt-dlpへフォールバックするため、通常はyt-dlp未導入でも動作しますが、保険として入れておくと安心です。

**mux実装**
: ダウンロードした映像と音声を1つのmp4に結合（mux）する処理の実装です。「mediabunny」はJavaScript実装でffmpeg不要（デフォルト）、「ffmpeg」は外部ツールのffmpegを呼び出します。mediabunnyを選んで失敗した場合はyt-dlpへの自動フォールバックが行われない点に注意してください。

**too many request（429）待機時間**
: コメント取得時にニコニコ側からアクセス過多（HTTP 429）の応答が返った場合、次のリトライまで待機する秒数です（デフォルト185秒、最大5回リトライ）。0にするとリトライせず即座に失敗扱いになります。

**ライブラリ表示形式**
: ライブラリタブの一覧をリスト表示（タイトル・時間・再生数を行で並べる）にするか、グリッド表示（サムネイルを大きく並べるYouTube風）にするかです。

**ライブラリデフォルトソート**
: ライブラリタブを開いたときの初期並び順です。ソートカラム（投稿日／DL日／タイトル／時間／再生数）と昇順・降順を指定できます。

## スケジュール

**自動ダウンロードスケジュール**
: 登録したマイリストを指定の曜日・時刻に自動チェックし、新着動画があれば自動でダウンロードキューに追加する機能です。名前・対象マイリスト・曜日（複数選択可）・実行時刻（HH:MM）・有効/無効を設定して保存します。例えば「毎週月・水・金の3時にお気に入りマイリストを更新」といった運用ができます。対象にできるのは事前にマイリストタブへ登録済みのマイリストのみです。

## プレイヤー

**コメント表示**
: プレイヤー上に流れるニコニコ動画のコメントの見た目を調整します。不透明度（薄く/濃く）、サイズ倍率（0.5〜2.0倍）、1つのコメントが画面を流れる表示秒数（1〜8秒、長いほどゆっくり流れる）、フォント名の指定、ボールド、縁取りの有無と濃さ、アンチエイリアスのON/OFFがあります。「コメントアート（CA）保護」をONにすると、歌詞コメントやAA（アスキーアート）のようにスペースの詰め方が重要なコメントがズレて崩れにくくなります。

**ストリーミング再生**
: 動画再生の方式を選びます。まず「ストリーミング（NNDD-RE内蔵プレイヤー）」か「ニコニコ公式プレイヤー埋め込み（webview）」かを選択します。内蔵プレイヤーを選んだ場合、さらにサブオプションとして「HLS即時再生（ネイティブ）」（デフォルト。hls.jsでニコニコCDNに直接アクセスし、即座に再生開始・シークも可能・コメント描画あり）か「HLS即時再生（プロキシ）」（内蔵HTTPプロキシを経由してアクセス。ネイティブ方式で問題がある環境向け）かを選べます。ニコニコ公式プレイヤーを選んだ場合は「NNDD-REのログイン情報を引き継ぐ」（デフォルトON）で、埋め込み表示にもNNDD-REのログインCookieを渡すかどうかを選べます。ニコニコ公式プレイヤーは音声のみ再生には対応していません。

**コメント一覧**
: 「過去ログ同時描画制限」は、過去コメントを表示するときに同時に描画する上限件数です（0=無制限）。コメント数が非常に多い動画で描画が重くなる場合に上限を設けるとパフォーマンスが安定します。「表示方式」は、コメント一覧をサイドパネル内のタブとして表示するか、動画の上に重ねてドラッグ移動できる浮動ウィンドウとして表示するかです。

**再生**
: デフォルト音量、動画ごとの音量差を自動で均す「音量ノーマライズ」（静かな動画は持ち上げ、大音量な動画はピークを抑える）、デフォルトの再生速度（0.5x〜2.0x）、デフォルト画質（自動=最高画質を含む選択肢。指定画質が存在しない動画では自動的に最高画質にフォールバック）、動画終端で自動的に最初から繰り返す「リピート再生」、動画説明文中のsm/nm/so等のリンクをクリックした際にNNDD-RE内でストリーミング再生する「動画リンクをプレイヤーで開く」、前回の再生位置を覚えておいて次回そこから再開する「続きから再生する」、シークバーやボタンなどコントロールバー全体の大きさ（小・標準・大）を設定できます。

## NGコメント

**NG強度プリセット**
: 「弱」はNGワードの完全一致のみを非表示、「中」（デフォルト）は部分一致も非表示にし、「強」はそれに加えて短時間に連投されたコメントも自動的に非表示にします。

**NG登録**
: NGワード（部分一致・完全一致を選べます）、NGユーザーID、NGコマンド（big/small等のコメント装飾コマンド）の3種類を個別に登録できます。ここで登録した内容はNNDD-RE内の全動画再生に共通で適用され、プレイヤー画面でコメントを右クリックしてもここと同じNGリストに追加できます。

## 外部ツール

**yt-dlp / ffmpeg**
: ダウンロード機能が利用する外部コマンドラインツールの状態確認とパス設定です。それぞれ検出状況（見つかったバージョン、または未検出）が表示され、パス欄を空欄にしておくとシステムのPATHと `userData/bin` フォルダから自動的に探索されます。特定バージョンを使いたい場合や自動探索がうまくいかない場合は「参照...」で実行ファイルを直接指定できます。yt-dlpは常にアプリ内から直接インストール/更新が可能です。ffmpegはWindowsでwingetが使える環境なら自動インストール/更新に対応し、それ以外の環境（Mac/Linux等）ではコマンド例（`brew install ffmpeg` 等）が案内として表示されるだけで、手動でのインストールが必要です。

## 接続診断

**診断を実行**
: ニコニコ動画側の各APIエンドポイントに実際にアクセスし、疎通できるか・ログイン状態が正しく認識されているかを一覧で確認します。ダウンロードや再生がうまくいかないとき、ネットワークやログインのどこに問題があるかを切り分けるために使います。

**フォローAPI診断**
: 「フォロー中」タブが使用しているAPIエンドポイント個別の動作確認です。フォロー中の新着が表示されない・古いといった不具合の調査に使い、結果はテキストとしてコピーしてバグ報告に添付できます。

## ログ

**ログレベル**
: 「標準」は通常運用に必要な情報のみ、「詳細」はAPIリクエストの中身なども含めた詳細なログを出力します。不具合調査を依頼された際は「詳細」に切り替えてから再現操作を行うと、原因特定に役立つログが残ります。

**自動ローテーション**
: ログファイルが際限なく肥大化しないよう、1ファイルの上限サイズ（MB）と保持する世代数を指定できます。上限を超えると新しいファイルに切り替わり、古い世代から削除されます。

**表示エリアの操作**
: 「再読込」で最新ログを取得、「ファイルを開く」でログファイルをエクスプローラー等で直接開けます（サポートへの添付用）、「ログをクリア」で内容を消去します。

## 情報

**バージョン / パス情報**
: 現在のNNDD-REのバージョンと、データベース・Cookie・ログ・キャッシュ・ライブラリ各種のファイルパスを確認できます。各行はクリックでパスをクリップボードにコピーでき、不具合報告時にファイルの場所を伝えるのに便利です。

**アップデートチャンネル**
: 「安定版」は正式リリースのみを更新対象にします。「ベータ版」は正式リリース前のベータ版も対象に含めるため、新機能を早く試せる代わりに不具合が含まれる可能性があります。

**起動時のアップデート確認**
: 「確認する」は新しい更新が見つかった場合にダイアログで知らせ、ダウンロード・インストールの実行はユーザーの判断に委ねます。「自動更新」は自動でダウンロードまで行い、次回終了時に自動でインストールします（通知のみ表示）。「確認しない」は起動時のチェック自体を行いません。「更新を確認」ボタンでその場で手動チェックすることもできます。

## バックアップ

**GitHub Gistバックアップ/同期**
: アプリ設定・NGリスト・マイリスト・スケジュール・保存検索・プレイリスト・視聴履歴を、GitHubアカウントに紐づくGist（非公開の保存領域）にアップロード/ダウンロードして、複数端末間で同じ設定を使い回せるようにする機能です。ログインはGitHub Device Flow方式（表示されたコードをブラウザ側で入力する方式）で行います。

**プロファイル**
: バックアップ対象を複数のプロファイルとして管理できます。既存のGistに紐付けて使うことも、新規に作成することも可能です。プロファイルごとにバックアップする範囲（データスコープ）を選べます。

**自動アップロード**
: プロファイルごとにONにすると、NNDD-RE起動時・終了時に自動でアップロードが行われます（前回アップロード時から変更がなければ通信自体をスキップします）。手動での「アップロード」ボタンも常に使えます。一方でダウンロード（Gistの内容をローカルへ反映する操作）は、誤って手元の設定を上書きしてしまう事故を防ぐため、常に手動実行のみです。

## デバッグ（開発者モード有効時のみ）

**APIダンプ**
: 動画再生時にニコニコ側とやり取りするAPIの生レスポンス（Watch v3/v3_guest API・セッション確立API・コメント取得API）をJSONファイルとして保存する機能です。バグ報告や仕様調査のために実際の通信内容を確認したい場合に使います。保存先は指定でき、未設定時はプロジェクトルート直下の `apitest` フォルダになります。3種類のダンプ対象はそれぞれ個別にON/OFFできます。通常利用ではオフのままで問題ありません。
