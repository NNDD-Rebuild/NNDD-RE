# 設定リファレンス

設定画面は左側のタブで11個（+開発者モード時のみ「デバッグ」）に分かれています。各タブの項目を一覧します。

## 全般

### 動画の保存先
- ダウンロードしたファイルの保存先フォルダ（デフォルト: `Documents/NNDD-RE/library/Downloads`）
- 「参照...」で変更、「開く」でエクスプローラー表示、「デフォルトに戻す」で初期値に戻す

### ニコニコ動画 ログイン
- **メールでログイン**: アプリ内でメールアドレス/電話番号＋パスワードを入力（2段階認証が必要な場合は6桁コード入力画面に遷移）
- **ブラウザでログイン**: 別ウィンドウで公式ログインページを開く
- ログイン画面には上記2つに加え、SSOログイン（Apple / Google / LINE / X / Facebook）ボタンもある
- 「パスワードを保存して次回から自動ログイン」チェックで次回以降ワンクリック/自動ログイン可能。ログイン中は「ID・PASS削除」で保存済み認証情報を削除できる

### プライバシー
- **視聴履歴を残さない**: ONで動画再生・DL時にCookieを送らずゲスト扱いでアクセス（年齢制限・チャンネル会員限定動画は視聴/DL不可になる場合あり）
- ON時のみ表示: 年齢制限等で再生できない動画への対応方針（毎回確認する / 常に履歴を残して再生する / 常に再生しない）

### 視聴履歴
- ランキング・フォロー中・マイリストへの再生済みバッジ表示 ON/OFF（デフォルト ON）。アプリ内視聴記録とニコニコ本家視聴履歴（起動時自動取得）の両方が対象

### 内蔵HTTPサーバー
- 起動/停止ボタン、起動中は `http://127.0.0.1:<port>/library` へのリンクとQRコード表示
- **LAN内からのアクセスを許可**（スマホ等から閲覧、要ファイアウォール許可）
- **起動時に自動起動する**
- **ポート**（デフォルト `12345`、変更は再起動後反映）
- **動画ファイルのストリーミング配信を許可**（スマホ・WEBクライアント用）
- **マイリスト情報の共有を許可**

### LANライブラリ（リモートNNDD参照）
- 同一LAN上の本家NNDD/NNDD-REのライブラリを参照する ON/OFF
- IPアドレス・ポート（本家NNDDデフォルトポート `12300`）

### システムトレイ
- トレイアイコン表示 ON/OFF
- ウィンドウを閉じたらトレイに最小化（DL続行可能）

### ウィンドウの大きさ・位置をリセットする
- ボタン1つでウィンドウサイズを 1280×800（最大化解除）に戻す

### 画像キャッシュ（サムネイル・アイコン）
- キャッシュ有効/無効、上限サイズ（MB、0=無制限）
- 現在のファイル数・使用量表示、「更新」「キャッシュを削除」ボタン

### Discord連携（Rich Presence）
- 再生中動画をDiscordステータスに表示 ON/OFF
- 表示内容の個別切替: 動画タイトル / 経過時間 / サムネイル画像 / GitHubリポジトリへのリンクボタン
- Discordデスクトップアプリの起動が必要。リンクボタンは他ユーザーから見た時のみ表示される（Discord仕様）

### Webhook通知（Discord / Slack）
- ダウンロード状況のWebhook通知 ON/OFF
- Webhook URL入力（URLのドメインからDiscord/Slackを自動判別）
- 通知タイミング: ダウンロード完了時 / 失敗時（個別ON/OFF）

### 開発者オプション
- 開発者モードを有効にすると設定画面に「デバッグ」タブが追加表示される

## ランキング・検索・マイリスト

### 表示形式
- デフォルト表示: グリッド（サムネイル大）/ リスト（コンパクト）
- センシティブな動画を隠す ON/OFF（デフォルト ON、OFFでR18等の閲覧注意動画もランキング等に表示）

### アプリ起動・UI
- 起動時のタブ（ランキング / 検索 / マイリスト / DLリスト / ライブラリ / 履歴 / 設定）
- テーマ（ダーク / ライト）

## DLリスト・ライブラリ

### ダウンロード
- 同時ダウンロード数（1〜10、デフォルト 2）
- リトライ回数（失敗時の自動リトライ）
- DL間クールダウン（秒、0=無効。1動画完了後、次開始までの待機）
- DL帯域制限（Mbps、0=無制限。yt-dlp / ネイティブHLS両方式に適用）
- 全コメント取得（新規DL時に過去コメントを全件取得するか。OFFで今コメのみ）
- easyコメント取得（全コメDL時にeasyスレッド＝増量コメントを含めるか。DL時間が大幅増加する場合あり）
- 音声のみDL時はコメントを取得しない（デフォルト ON）
- 動画DL方式: ネイティブHLSダウンロードを優先する（OFFで常にyt-dlp使用。失敗時は自動でyt-dlpにフォールバック）
- mux実装: `mediabunny`（JS実装、ffmpeg不要・デフォルト）/ `ffmpeg`（mediabunny失敗時はyt-dlpへフォールバックしない）
- too many request（429）待機時間（秒、0=リトライなし。コメント取得時、最大5回リトライ、デフォルト185秒）

### ライブラリ表示形式
- リスト表示（タイトル・時間・再生数を一覧）/ グリッド表示（サムネイル大きく、YouTube風）

### ライブラリデフォルトソート
- ソートカラム（投稿日 / DL日 / タイトル / 時間 / 再生数）
- 並び順（昇順 / 降順）

## スケジュール

自動ダウンロードスケジュールの一覧・追加・編集・削除。

- 名前・対象マイリスト・曜日（複数選択可）・時刻（HH:MM）・有効/無効
- 指定した曜日・時刻に対象マイリストを自動更新し、新着動画をダウンロード
- マイリストが1件も登録されていない場合は先にマイリストタブでの登録が必要

## プレイヤー

### コメント表示
- コメント表示 ON/OFF
- 不透明度（10〜100%）、サイズ倍率（0.5〜2.0倍、プリセットボタン0.75/1.0/1.25/1.5あり）
- 流れるコメント表示秒数（1〜8秒）
- フォント（自由入力）、ボールド、文字の縁取り ON/OFF＋濃さ（薄い/普通）
- アンチエイリアス ON/OFF
- コメントアート（CA）保護（ONで歌詞・AA等のズレを抑制）

### ストリーミング再生
2段階の選択式:
1. **ストリーミング（NNDD-RE内蔵プレイヤー）**か **ニコニコ公式プレイヤー埋め込み（webview）**か
2. ストリーミング選択時のサブオプション: **HLS即時再生（ネイティブ）**（デフォルト、即時再生・シーク可・コメント描画あり）か **HLS即時再生（プロキシ）**（内蔵HTTPプロキシ経由）
3. ニコニコ公式選択時: 「NNDD-REのログイン情報を引き継ぐ」（ONでnicovideo.jp Cookieを埋め込みプレイヤーに注入、デフォルトON）

### コメント一覧
- 過去ログ同時描画制限（0=無制限、件数指定可）
- 表示方式: タブ表示（サイドパネル内）/ 浮動ウィンドウ（ビデオ上に重ねてドラッグ移動可）

### 再生
- デフォルト音量、音量ノーマライズ（動画間の音量差を自動平滑化）
- デフォルト再生速度（0.5x〜2.0xのプリセットボタン）
- デフォルト画質（自動=最高画質 / 1080p以下 / 720p以下 / 480p以下 / 360p以下。無ければ自動的に最高画質へフォールバック）
- リピート再生 ON/OFF
- 動画リンクをプレイヤーで開く（説明文中のsm/nm/so等のリンクをNNDD-REでストリーミング再生）
- 続きから再生する（前回の再生位置を記憶。OFF時は常に最初から）
- コントロールUIサイズ（小 / 標準 / 大）

## NGコメント

- NG強度プリセット: 弱（完全一致のみ）/ 中（部分一致も適用、デフォルト）/ 強（連投コメントも自動非表示）
- NG登録: NGワード（部分一致/完全一致を選択可）・NGユーザーID・NGコマンドの3種
- プレイヤー内の右クリックからも同じNGリストに追加可能。登録したNGは全動画に適用される

## 外部ツール

- **yt-dlp** / **ffmpeg** それぞれについて: 検出状態（バージョン表示）、パス指定（空欄=自動探索、PATH + `userData/bin`）、「参照...」でファイル選択
- インストール/更新ボタン（yt-dlpは常時、ffmpegはWindowsでwinget利用可能時のみ自動インストール対応。それ以外はコマンド例を表示、例: `winget install Gyan.FFmpeg` / `brew install ffmpeg` / `sudo apt install ffmpeg`）

## 接続診断

- 「診断を実行」でニコニコ動画各エンドポイントへの疎通確認とログイン状態を一覧表示（結果・HTTPステータス・応答時間）
- 「フォローAPI診断」でフォロー中タブが使用するAPIエンドポイントの動作確認（結果をコピー可能）

## ログ

- アプリログのリアルタイム表示（自動再読込 3秒間隔、切替可）
- ログレベル: 標準 / 詳細
- 自動ローテーション: 上限サイズ（MB）・保持世代数
- 「再読込」「ファイルを開く」「ログをクリア」ボタン

## 情報

- バージョン表示、パス情報（userData / ライブラリDB / Cookie / ログ / キャッシュ / ライブラリの各パス、クリックでコピー）
- アップデートチャンネル: 安定版 / ベータ版
- 起動時のアップデート確認: 確認する（ダイアログで尋ねる）/ 自動更新（自動DL、終了時に自動インストール）/ 確認しない
- 「更新を確認」ボタンで手動チェックも可能

## バックアップ

GitHub Gist を使ったアプリ設定・NGリスト・マイリスト・スケジュール・保存検索・プレイリスト・視聴履歴のバックアップ/同期。

- GitHub Device Flow でログイン（ブラウザでコード入力）
- プロファイル単位で管理（複数プロファイル作成・切替可）、既存Gistとの紐付けも可能
- バックアップ範囲（データスコープ）をプロファイルごとに設定
- 「起動時・終了時に自動アップロード」ON/OFF（前回から変更なければスキップ）
- アップロードは手動/自動どちらも可、**ダウンロード（ローカルへの反映）は誤操作防止のため常に手動**

## デバッグ（開発者モード有効時のみ）

全般タブの「開発者オプション」をONにすると表示される、開発者向けタブ。

- API生データ（Watch v3/v3_guest API・セッション確立API・コメント取得API）をJSONファイルへダンプする機能
- 保存先フォルダ指定（未設定時はプロジェクトルート直下の `apitest`）
- ダンプ対象を個別に選択可能
