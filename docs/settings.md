# 設定リファレンス

設定画面は、左側のメニューで12個（開発者モードのときだけ「デバッグ」が加わります）に分かれています。各項目が何をするものかを説明します。

内蔵HTTPサーバー、GitHub同期、Discord連携は、それぞれ専用のページがあります。

## 全般

**動画の保存先**
: ダウンロードした動画・コメントの保存先フォルダです。初期値は `ドキュメント/NNDD-RE/library/Downloads` です。「参照...」で、外付けドライブやNAS上のフォルダなど、任意のフォルダに変更できます。変更後は、新しいダウンロード分だけが新しい場所に保存され、既存のファイルは移動されません。

**ニコニコ動画 ログイン**
: ログインの方法は、[使い方ガイド](/NNDD-RE/usage-guide/)を参照してください。ログイン中は「ログアウト」ボタンが表示され、ID・パスワードを保存している場合は「ID・PASS削除」も表示されます。「ブラウザでログイン」では、パスワードがアプリに保存されません。共有のPCなどで使うときに向いています。

**プライバシー: 視聴履歴を残さない**
: ONにすると、動画の再生・ダウンロードのときに、ログイン情報を送らず、ゲストとしてアクセスします。ニコニコ動画側の、アカウントの視聴履歴に残したくないときに使います。副作用として、年齢制限のある動画やチャンネル会員限定の動画は、ログインが必要なため、視聴・ダウンロードできなくなることがあります。そのときの動作は、次の3つから選べます。「毎回確認する」（そのたびにダイアログで聞きます）、「常に履歴を残して再生する」（その動画だけ、ログインした状態でアクセスします）、「常に再生しない」（スキップします）。

**システムトレイ**
: 「トレイアイコンを表示」で、タスクトレイにアイコンを常駐させます。「ウィンドウを閉じたらトレイに最小化」をONにすると、×ボタンでウィンドウを閉じても、アプリは終了せず、ダウンロードが続きます。完全に終了するときは、トレイのアイコンから終了を選びます。

**ウィンドウの大きさ・位置をリセットする**
: ウィンドウが画面の外に出てしまったときなどに、大きさ1280×800、最大化なしの初期状態に戻します。

**開発者オプション**
: 「開発者モードを有効にする」（初期値はOFF）をONにすると、設定の左メニューに「デバッグ」が加わります。通常の利用では必要ありません。

## 表示・検索

**デフォルト表示**
: ランキング・検索・マイリストの一覧を、グリッド表示（サムネイルが大きい）にするか、リスト表示（コンパクト）にするかの初期値です。初期値はグリッド表示です。開いた後も、画面上部のボタンで切り替えられます。

**センシティブな動画を隠す**
: 初期値はON。OFFにすると、閲覧注意のフラグが付いた動画も、ランキングや検索結果に表示されます。

**検索API**
: 検索タブで使う検索の方式です。「スナップショット」（初期値）は、1日に1回更新されるため、新着動画が検索に出るまで、最大1日ほどかかります。タグの完全一致検索の精度は高めです。「nvapi（即時反映）」は、投稿したばかりの動画もすぐ検索できますが、検索結果にタグの情報が含まれないため、動画情報のタブでタグを表示できません。

**入力履歴**
: 「検索履歴を保存する」「マイリストの閲覧履歴を保存する」で、それぞれの入力の履歴を残すかどうかを選べます（どちらも初期値はON）。それぞれ「履歴を消去」ボタンで履歴を消せます。検索ワード欄とマイリストのURL欄には、直近10件が候補として表示されます。

**起動時のタブ**
: ランキング / 検索 / マイリスト / DLリスト / ライブラリ / 履歴 / 設定から選ぶ項目です。ただし、現在のバージョンでは、この設定は起動時の表示に反映されず、常にランキングタブで起動します。

**テーマ**
: 画面全体の配色を、ダーク（初期値）/ ライトで切り替えます。

**視聴履歴: 再生済みバッジ**
: 初期値はONです。ランキング・検索・フォロー中・マイリストの動画に、「視聴済み」のバッジを表示するかどうかです。判定には、このアプリで再生した記録と、ニコニコ動画の視聴履歴（起動時に自動で取得します）の両方を使います。そのため、他の端末やブラウザで見た動画にもバッジが付きます。

## ダウンロード

「ダウンロード」と「スケジュール」の2つのタブがあります。

### ダウンロード

**同時ダウンロード数**
: 一度に並行してダウンロードする動画の本数です（1〜10、初期値は2）。増やすと全体が早く終わりますが、回線の帯域や、ニコニコ側のアクセス制限に引っかかりやすくなります。

**リトライ回数**
: ダウンロードが失敗したときに、自動で再試行する回数です（0〜10、初期値は3）。

**DL間クールダウン**
: 1本のダウンロードが終わってから、次を始めるまでに待つ秒数です。0（初期値）だと、待たずに次へ進みます。設定できる範囲は0〜60秒です。短い間隔で大量にダウンロードしてアクセス制限に当たるときは、数秒〜数十秒の間隔を空けると安定します。

**DL帯域制限**
: ダウンロードの通信速度の上限（Mbps）です。0（初期値）は無制限で、yt-dlp とネイティブHLSのどちらの方式にも適用されます。ダウンロード中に、ビデオ会議など他の通信を圧迫したくないときに使います。

**全コメント取得 / easyコメント取得**
: 「全コメント取得」をONにすると、新しくダウンロードするときに、その動画の投稿以来の過去のコメントを、すべて取得します（初期値はOFF。OFFの場合は、今コメ（直近のコメント）だけです）。「easyコメント取得」は、全コメント取得のときに、通常のコメントに加えて、かんたんコメント（増量コメント）も取得するかどうかです。初期値はOFFで、ONにすると、コメントの数によっては、ダウンロードの時間が大きく伸びます。

**音声のみDL時はコメントを取得しない**
: 初期値はONです。音声だけをダウンロードするときは、コメント取得を省いて、時間を節約します。

**生放送のタイムシフトを live フォルダにダウンロードする**
: ONにすると、生放送のタイムシフトの保存先を、`live` フォルダにします（初期値はOFF。OFFのときは通常の動画と同じフォルダです）。

**ネイティブHLSダウンロードを優先する**
: ONにすると、NNDD-RE の内蔵の方式で、ニコニコの動画を直接ダウンロードします（初期値はON）。OFFにすると、常に外部ツールの yt-dlp を使います（この場合、音声のみのダウンロードはできなくなります）。ONのときも、失敗した場合は yt-dlp に切り替えて再試行します（mux実装で「mediabunny」を選んでいる場合を除く）。

**mux実装**
: ダウンロードした映像と音声を、1つのファイルに結合する方式です。「mediabunny」（初期値）は、アプリ内蔵の方式で、FFmpeg は不要です。「ffmpeg」は、外部ツールの FFmpeg を使います。「mediabunny」を選んでいると、失敗しても yt-dlp には切り替わりません。詳しくは[トラブルシューティング](/NNDD-RE/troubleshooting/)を参照してください。

**too many request（429）待機時間**
: コメント取得のときに、ニコニコ側から、アクセスが多すぎるという応答が返ってきた場合に、次の再試行まで待つ秒数です（0〜300秒、初期値は185秒、再試行は最大5回）。0にすると、再試行せず、すぐに失敗になります。

### スケジュール

**自動ダウンロードスケジュール**
: 指定した曜日・時刻に、新着動画を確認して、自動でダウンロードキューに追加する機能です。名前、対象（マイリスト / シリーズ / フォロー中の投稿者）、曜日、時刻、「対象の名前でフォルダを作成して保存」、有効 / 無効を設定します。詳しくは[DLリスト](/NNDD-RE/download/)を参照してください。

## ライブラリ

**ライブラリ表示形式 / デフォルトソート**
: ライブラリタブの表示を、リスト表示（初期値）にするか、グリッド表示にするかと、開いたときの並び順です。並び順の列は、投稿日（初期値）/ DL日 / タイトル / 時間 / 再生数から選べ、昇順（初期値）・降順を選べます。

**画像キャッシュ（サムネイル・アイコン）**
: 動画のサムネイルや投稿者のアイコンを、PCに保存しておく機能です。一度表示した画像は、次回から、通信せずに表示できます。有効・無効を切り替えられ（初期値は有効）、上限のサイズ（MB、初期値は1000）を超えると、古いものから削除されます（0にすると無制限）。「キャッシュを削除」で、すべて消せます。

## プレイヤー

**コメント表示**
: プレイヤー上を流れるコメントの見た目を調整します。「コメントを表示する」、不透明度（10〜100%）、サイズ倍率（0.5〜2.0倍）、流れるコメントの表示秒数（1〜8秒、初期値は3秒）、フォント、ボールド、文字の縁取り（初期値はON）と縁の濃さ（薄い（初期値）/ 普通）、アンチエイリアス、「投稿者フィルターを有効にする」（初期値はON。本家NNDDで保存した動画のコメントにだけ効きます）があります。「コメントアート（CA）保護」（初期値はON）をONにすると、歌詞コメントやAA（アスキーアート）のような、スペースの詰め方が大事なコメントが崩れにくくなります。

**ストリーミング再生**
: 動画の再生方式を選びます。まず、「ストリーミング（NNDD-RE内蔵プレイヤー）」か、「ニコニコ公式プレイヤー埋め込み」かを選びます。内蔵プレイヤーでは、さらに「HLS即時再生（ネイティブ）」（初期値。すぐに再生が始まり、シークでき、コメントも表示されます）か、「HLS即時再生（プロキシ）」（ネイティブ方式で問題が出る環境向けです）を選べます。ニコニコ公式プレイヤーを選んだときは、「NNDD-REのログイン情報を引き継ぐ」（初期値はON）で、ログイン情報を渡すかどうかを選べます。ニコニコ公式プレイヤーは、音声のみの再生に対応していません。

**コメント一覧**
: 「過去ログ同時描画制限」は、過去のコメントを表示するときに、同時に描画する件数の上限です（0は無制限）。コメントが非常に多い動画で、描画が重いときに設定します。「表示方式」は、コメント一覧を、サイドパネルのタブにするか、ドラッグで動かせる浮動ウィンドウにするかです。

**再生**
: 初期の音量、動画ごとの音量の差をならす「音量ノーマライズ」、初期の再生速度（0.25x〜2.0x）、動画を切り替えても直前に選んだ再生速度を使い続ける「再生速度を次の動画に引き継ぐ」（初期値はOFF）、初期の画質（「自動」は最高画質です。指定した画質がない動画では、最高画質になります）、動画の最後まで再生したら最初から繰り返す「リピート再生」、動画の説明文にある sm / nm / so のリンクをクリックしたとき、NNDD-RE 内で再生する「動画リンクをプレイヤーで開く」、前回の再生位置から再開する「続きから再生する」、コントロールバーの大きさ（小・標準（初期値）・大）、ウィンドウ表示時にコントロールバーを自動で隠さず常に表示する「コントロールバーを常時表示」（初期値ON。フルスクリーン時は自動で隠れます）を設定できます。

**＠ジャンプ**
: 投稿者コメントの「＠ジャンプ」コマンドを、どう扱うかを選びます。「確認して移動」（初期値。別の動画へ移るときだけ確認します）、「確認せず移動」、「無効」（動画内の移動・ラベルも動きません）から選べます。

## 生放送

[生放送](/NNDD-RE/live/)の「設定」の節を参照してください。次の項目があります。

- **別の番組を新しいウィンドウで開く**（初期値はOFF）
- **放送者の移動指示に自動で従う**（初期値はOFF）
- **フォロー中の放送者が生放送を始めたら通知する**（初期値はOFF）と、その確認の間隔（初期値は5分、最短1分）
- **コメントリストの表示方式**（タブ表示 / 浮動ウィンドウ）
- **コメントウィンドウを最前面に表示する**（初期値はON）

NCV（ニコ生コメントビューア）との連携は、「外部ツール・連携」の「外部ツール」にあります。

## NGコメント

**NG強度プリセット**
: 弱 / 中 / 強のボタンで切り替えます。「弱」は、NGワードの完全一致だけを非表示にします。「中」（初期値）は、部分一致も非表示にします。「強」は、さらに、短い時間に連投されたコメントも、自動で非表示にします。

**NG登録**
: NGワード（部分一致・完全一致を選べます）、NGユーザーID、NGコマンド（big / small などの装飾コマンド）、許可IDを登録します。登録済みの一覧から削除もできます。ここで登録した内容は、NNDD-RE のすべての動画の再生に適用されます。プレイヤーで、コメントを右クリックして追加することもできます。

**ニコニコのNG設定との同期**
: 「追加・削除をニコニコ側にも反映する」（初期値はOFF、ログイン中のみ使えます）をONにすると、NNDD-RE で追加・削除したNGを、ニコニコ動画側のNG設定にもすぐ反映します。「今すぐ同期」で、前回の同期との差分を、追加も削除も双方に反映します（初回は足し合わせるだけで、何も消えません）。対象は「NGワード（部分一致）」と「NGユーザーID」で、完全一致ワード・コマンド・許可IDは NNDD-RE だけで保持します。


## 外部ツール・連携

「外部ツール」「通知・連携」「サーバー・LAN」の3つのタブがあります。

### 外部ツール

**yt-dlp / ffmpeg**
: ダウンロードで使う外部ツールの状態確認と、場所の設定です。それぞれ、見つかったバージョン、または未検出が表示されます。パスを空欄にすると、システムの PATH などから、自動で探します。「参照...」で、実行ファイルを指定することもできます。yt-dlp は、アプリ内から、導入・更新できます。ffmpeg は、Windows と Linux で、アプリ内から導入・更新できます。macOS では、`brew install ffmpeg` などで、自分で導入してください。

**外部プレイヤー**
: ONにして実行ファイルを指定すると、VLC や mpv などの外部のプレイヤーで、動画を再生します。

**NCV**
: NCV（ニコ生コメントビューア）との連携です。「生放送を開くとき NCV も起動する」（初期値はOFF）、「タイムシフト視聴時も起動する」（初期値はON）、NCV の実行ファイルのパス、生放送を開いてから NCV を起動するまでの待ち時間（0〜60秒、初期値は3秒）を設定します。

### 通知・連携

**Discord連携 / Webhook通知**
: [Discord連携・Webhook通知](/NNDD-RE/discord-webhook/)を参照してください。

**チャンネル新着監視**
: 登録したチャンネルの新着動画を、一定の間隔で確認して通知する機能です。初期値はOFFで、確認の間隔（分、5分以上、初期値は30分）を設定できます。マイリストタブに登録済みのチャンネルが対象で、新着動画をトレイ通知します。Webhook通知を設定している場合は、そちらにも通知します。DLキューへの自動追加はしません。設定の変更は次回の起動時に反映されます。

### サーバー・LAN

**内蔵HTTPサーバー / LANライブラリ**
: 他の端末からライブラリを見る機能と、別のNNDD / NNDD-REのライブラリを見る機能です。[内蔵HTTPサーバー・LAN共有](/NNDD-RE/http-server-integration/)を参照してください。

**Tailscale**
: 内蔵HTTPサーバーを、Tailscale のネットワークに参加させるための、ツールの取得・更新・削除と、ログインの管理です。[内蔵HTTPサーバー・LAN共有](/NNDD-RE/http-server-integration/)を参照してください。

## バックアップ・移行

GitHub の Gist を使った、設定のバックアップと同期です。[GitHub同期・バックアップ](/NNDD-RE/github-sync/)を参照してください。

**アカウントのデータ移動**
: マイリスト登録・自作プレイリスト・スケジュール・生放送の録画予約は、アカウントごとに持ちます。誤ったアカウントに紐づいたデータなどを、別のアカウントへ移動・コピーします。

**本家NNDDからインポート**
: 本家NNDDの設定・NGリスト・マイリスト・保存検索・履歴・プレイリスト・ライブラリ情報を取り込みます。ログイン情報は取り込めません。[NNDDからの移行](/NNDD-RE/migrate-from-nndd/)を参照してください。

## 情報・更新

**バージョン / パス情報**
: 今のバージョンと、userData・ライブラリDB・Cookie・ログ・キャッシュ・ライブラリの保存先を確認できます。各行をクリックすると、パスをコピーできます。

**アップデート**
: 起動時の確認の方法（確認する / 自動更新 / 確認しない）、チャンネル（安定版 / ベータ版）、手動の確認です。[インストール・アップデート](/NNDD-RE/install/)を参照してください。

**匿名の利用統計**
: 匿名の利用統計を送るかどうかを選びます。送る内容と、「送信内容を見る」「匿名IDを作り直す」は、[プライバシー](/NNDD-RE/privacy/)を参照してください。

## 接続診断

**診断を実行**
: ニコニコ動画側の各APIに、実際にアクセスして、つながるか、ログイン状態が正しく認識されているかを、一覧で確認します。ダウンロードや再生がうまくいかないときに、ネットワークとログインのどこに問題があるかを切り分けるために使います。

**フォローAPI診断**
: 「フォロー中」タブが使っているAPIの動作確認です。フォロー中の新着が表示されない、古い、というときに使います。結果はテキストでコピーできるので、不具合の報告に添えられます。

## ログ

**ログレベル**
: 「標準」（初期値）は、通常の運用に必要な情報だけを、「詳細」は、通信の内容なども含めた、詳しいログを出力します。不具合を調べるときは、「詳細」に切り替えてから、操作をやり直してください。

**自動ローテーション**
: ログファイルが大きくなりすぎないように、1ファイルの上限のサイズ（MB、初期値は1）と、残す世代の数（初期値は3）を指定できます。

**表示エリアの操作**
: 「自動再読込」（初期値はON）をONにすると、3秒ごとに最新のログを取得します。「再読込」で最新のログを取得します。「ファイルを開く」で、ログファイルを直接開きます。「ログをクリア」で、内容を消します。

## デバッグ（開発者モードのときだけ）

不具合の調査用の機能です。通常の利用では、使う必要はありません。「API ダンプ」（動画ストリーミング時に取得するAPIの生データをJSONファイルに保存します。保存先と、ダンプ対象を選べます）と、「生放送 視聴フロー調査 (PoC)」（番組IDを指定して接続を試し、結果をログに出力します）があります。
